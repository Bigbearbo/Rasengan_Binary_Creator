# S1 recurrent hard-bit head: endpoint-only supervision, 2026-11-20

This is an independent test of the GPT suggestion to train a 0/1 forward threshold with a surrogate backward derivative, on the same frozen serial adder used in PR 136. Source: original serial_adder.py, byte-pinned at SHA256 6d5523276727d265211b1c35a950006053220b97c4489578a10540217e4e0d8d. The program constructs its original 19-unit matrices from original AST definitions, enumerates 65,536 8-bit input pairs, checks the old complete nine-bit sum and eighth-round-only STOP and captures A0/B0 at each round. The new private 1-cell register q has q0=0 and no route back to the 19 old units. Inputs for the single new threshold cell are (A0,B0,q_prev), plus bias; H(z)=1[z>=0]. This is an internal-board experiment with manually supplied topology. A raw SLE external opcode is not under evaluation.

Precommitted rules, before computing any results: 16 paired seeds 20261120 through 20261135, each using numpy.default_rng(seed).choice(65536,64,replace=False), where pair id=256*A+B. For all methods the sole teacher label per pair is A<B, observed only after round eight. No initial or intermediate q label, no hidden-target supervision; initialization of the register q0=0 is part of the definition. For gradient methods all four parameters start at zero and make 256 full-batch SGD attempts, rate 0.25, half mean squared endpoint error, float64. Use H for all forward steps; backward derivatives are (1) zero for the hard step, (2) identity straight-through, (3) 1[|z|<=1] straight-through, (4) identity stopping the gradient through q_prev (past predictions still enter the forward step). For the three time-dependent gradients perform explicit BPTT over all eight rounds with tied parameters. No adaptive learning rate, stopping, seed selection, or hyperparameter tuning. Count nonzero updates separately, record final parameters and all training ids.

A finite, non-gradient baseline enumerates 81 integer choices from {-1,0,1}^4 under the same endpoint labels. Choose least endpoint errors, then fewest nonzero weights/bias, then lexicographic order. Also retain how many hypotheses minimized the endpoint errors. Compute the final Boolean cell truth table over its eight input triples independently of held labels, compare (a) trained float weights, (b) direct np.rint of all four parameters with the same >=0 threshold, (c) an exact local truth-table translation to integer weights in [-2,2]^4 where one exists. For translation choose fewest nonzeros followed by lexicographic order; failure records no translated model. This uses outputs of the learned local gate, not true borrow labels. The above scheme may return a functionally equivalent set with different scale. Distinct methods and precision modes using the same truth table may share exhaustive execution results.

Test, using own previous q at inference: all 65,536 ordered pairs, all eight rounds, endpoint and all-eight-sequence accuracy; at-least-95% and 100% seed counts for each endpoint/trace/evaluation mode; record recall of true positive/negative labels. Reference round k (1-indexed) is (A modulo 2^k)<(B modulo 2^k). Signed or modulo difference output is not part of this task. Include every method/seed, paper/test distinctions, tool dependencies, file hashes, parameter/update/operation counts, former research ancestry. Report honestly if agreement with the baseline fails. No changes to shared project and no local team deployment.
