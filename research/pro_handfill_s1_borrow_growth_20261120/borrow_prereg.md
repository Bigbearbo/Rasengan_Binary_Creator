# S1 加一個借位單元的事前計畫

2026-11-20。目標是測量在已凍結逐位加法器上新增一條有方向的借位鏈。這是 Pro 的獨立小實驗，不變更原 S1 或正式學生。計畫寫於執行本組連續八輪與 16 種訓練順序前。首輪衝突與可能達成的 75% 上限已在設計時推導，屬既有假設。

## 輸入與固定條件

使用同目錄原始 `serial_adder.py` 的 `Net`、`full_add_bit`、`build_S1`、`board_of`、`val` 與常數 `M`。只載入這些 AST 定義，以避免依賴其他版本的 Windows 模組。保留原始 S1 19 個單元、18 個草稿位、交卷位，以及原 026 `READOUT`、`EXACT-TWO` 終態 JSON 內四個凍結零修正後的兩組 19 維整數讀出。記錄來源、程式、計畫 SHA-256。

## 比較與驗收

1. 依 256×256 有序輸入對，將原網路第一輪的完整 19 位隱藏向量分組。每組分別計算有借位與無借位的題數，以較大者的總和為任何只看這個向量的預測器在此域的正確數上限。並報恆猜無借位的分數。
2. 電路只加一個可讀 A0、B0、前一輪借位的整數門檻單元，以及一個初值 0、由新單元獨寫並於下一輪讀回的草稿位。舊單元不接新輸入，舊輸出不接新單元。手填組固定權重 `[-1, 1, 1]` 與偏置 `-1`，門檻為加總大於等於零。無回讀對照只移除新單元通往自身下一輪的連線，仍寫出本輪預測。
3. 同拓撲訓練組的三個輸入權重和偏置從 0 開始。用整數感知器，學習率 1，預測有誤時 `w += (目標−預測) × 輸入` 且 `b += 目標−預測`。教材窮舉八組局部二元三元組，標籤由 `a < b + borrow_in` 給出。使用種子 `20261120` 到 `20261135`，每一 epoch 以 NumPy `default_rng(seed)` 隨機排列八題，獨立種子各自至多 128 epochs。到 epoch 結束時重測同八題，全部正確就停止。保留全部種子、更新數與未收斂例，不選種子。
4. 所有組合窮舉 65,536 有序輸入對。預測值由網路自己寫入，回讀組連續讀回八輪，評量時以整數前綴比較 `a mod 2^k < b mod 2^k` 當第 k 輪借出真值。分別統計每輪、每題八輪全對、第八輪借位正確；參照不回饋答案。逐輪比原封存網路隱藏與草稿狀態，獨立核對舊和、原加法器草稿進位、兩個已學讀出與交卷節奏。相同權重的種子可共用同一次全域推論，逐一對應輸出與種子。
5. 用手填與全部 16 次訓練能否八輪全對、舊能力是否保留、取消回讀後是否下降來判斷。只測借位序列；未設計減法差值輸出。通道與新增容量由人指定，初始三元組真值全給予，不測自主選擇成長及未教過的局部規則。記錄可獨立重跑的程式與逐項分母。
