# Direct two-bit cell after an eight-step fine skill
Prospective. Evaluate the arithmetic component separately from learned route selection in the companion experiment. This study uses an internal addition board, not the external SLE question codec.
1. A one-bit threshold student is trained on each of the eight local (A bit, B bit, own carry) contexts once with exact two-bit targets. The 8 hard conjunction features each identify one context. Zero-initialized readout weights are set by a delta update with step size 1 to match the signed output labels (+1/-1), with >0 threshold (unseen outputs default 0). Verify independent free running for each of 65536 ordered input bytes, from initial zero carry and with the terminal ninth bit. This is a mastered fine skill with explicit local teaching.
2. Stage 2 uses 16 fixed seeds 20261120..20261135. With NumPy default_rng(seed).choice(65536,64,replace=False), id=256*A+B, each seeded sequence is nested at 1,2,4,8,16,32,64 distinct whole examples. Per example, four training records at bits 0/2/4/6. Demonstration arm: compute each record directly with reference integer two-bit arithmetic. Self arm: capture consecutive pairs of the trained student's actual one-bit decisions, combining intermediate outputs into two-bit digit and outgoing carry; record its own incoming carry. The two pipelines must be implemented independently. No outer teacher is called for self targets. An experimental negative control rotates the four targets of each paper by one against their unshifted inputs before fitting the structured self student at 64 examples.
3. Two prespecified direct hardware options. (LUT) 32 explicit conjunctions identify two-bit A and B plus cin; 3 readouts have 96 adjustable weights; present examples in order, each signed delta as in stage 1. (Linear) Five local bit coefficients in order A0,A1,B0,B1,cin and a constant are learned via minimum-norm least squares taking observed 3-bit targets as unsigned integers from 0 through 7. Solve from bounded 6x6 integer sufficient statistics (eigendecomposition/pseudoinverse with fixed rank tolerance 1e-10), round fitted coefficients to nearest integer (halves to even) at export. The fixed integer-to-three-bits encoder clips the predicted scalar to [0,7]. No input bit significance or arithmetic coefficient is initialized by the designer. Treat the linear-additive function class, binary output decoder, prealigned 2-bit input grouping and availability of own correct fine traces as hand-designed inductive bias. Fit is supervised identification, not gradient learning by final-answer reward. Direct replay makes one lookup or one six-term affine evaluation per two-bit tick and never calls the fine student inside a coarse tick.
4. Store example IDs, complete coefficient checkpoints, local coverage/rank/number of missing targets, target identity across teaching modes, and exhaustive 9-bit sums/each legal prefix and its carry/stop counts for all 65536 ordered pairs under fixed schedules (fine eight, coarse four). Count paper-perfect, unseen-only, and rate >=95% for the four-step full-trace metric. Just reaching the correct final answer does not pass a corrupted intermediate row. Input is read progressively; no true carry is substituted in rollout. The fixed baseline calls the issued actions only; no claim that arithmetic-only evaluation demonstrates policy learning. No retries or hardware/seed selection. Fine stop at position eight, coarse stop at same position; record macro clock versus direct cell, shifted input reads and result writes.
5. Raw fixture bytes per ordered pair: original A,B, then the four local digit+4*carry outputs of the self_linear model from seed 20261120 at size 64, unsigned bytes. Identical duplicates between teacher/self models are part of validation, not independent successes. Local truth table and whole-input replay are both compulsory. Upstream handfilled T3 checker compatibility is independently verified by separate audit when available.
