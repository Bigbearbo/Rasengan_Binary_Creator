# Exploratory recovery of the original stop and width cutoffs

Written after observing the main policy outcomes, before running this comparison. The original fine initializer has a working stop at R=0 and a wide-read cutoff at R=2. Its EC training changed four binary group entries, leaving those old correct cutoffs unmodified. To test whether terminal feedback plus round cost can discover the cutoffs too, initialize s=-1 and k=3, with the same all-zero map. This initializer does not submit even at R=0. Use the same 16 seeds, 64 training episodes, optimization and tests, adjusting no hyperparameters. Record all changed coefficients, terminal and scheduled verification for every test setting. Grade against the environment without setup corrections. Run a second exploratory ablation on the original EC readout with the first wrong s or k singly at evaluation; compare full width-eight layout performance to isolate each cutoff. The recovery comparison is separate from continuation of an already operational eight-step student.
