# Prospective stride-policy protocol (two independent read lanes)

Research question. Can an eight-step student learn when to advance one or two columns and when to submit, without an externally supplied step schedule? Arithmetic is held fixed and exact for the controller-only comparison. An independent joint replay can substitute the trained one/two-column arithmetic cells.

The environment gives width W, current head p (remaining count R=W-p), and the two raw one-bit bank identifiers at columns p,p+1 for each operand. At/beyond the end bank identifiers read zero. The pair read is physically available only when p+1<W and neither operand crosses a bank boundary; one read is legal whenever p<W. The participant never receives a legal-move flag, a target stride, a deadline or the reference trace at evaluation. R and the local bank identifiers are engineered, explicit inputs. Uniform tags reduce to the original unrestricted task. External memory boundaries constitute a constructed transfer condition.

Policy class. Learn integer STOP cutoff s in {-1,0,1}, wide-read cutoff k in {1,2,3}, and 16 binary weights indexed by the four raw bank-identifier bits. If R<=s choose STOP, else choose 2 if R>=k and the indexed weight is on, else choose 1. Bias to the supplied old one-column skill through initialization s=0,k=2, all weights off. This conditional policy is a small discrete readout with a fixed pattern decoder, not discovered circuitry. No fallback, forced last stride, implicit termination or clipping of an illegal move. A separate STOP decision is counted alongside arithmetic rounds in all branches.

Data. 16 seeds 20263101..116, 64 training episodes (ordered byte pair and independent lane layouts, all W=8; one quarter of episodes by index use constant bank bits, with random phase per lane; remaining layouts iid). The pair inputs/rewards and training episode order are identical across arms. No test-guided fitting. For reproducibility use NumPy default_rng(seed); record full episode list, all fitted readouts, training score and scoring code. Only integer scoring.

Controls. Old fixed one, fixed two (stop at the end, try two even at a singleton), teacher-programmed greedy oracle. Learned E uses only episode validity, final nine-bit answer and normal STOP on the training operands; learned EC additionally minimizes the number of arithmetic rounds. Learned I uses local labels from a greedy demonstration visiting training states. All learned arms use the same deterministic discrete coordinate search: initialize at the old skill; test every single change of one cutoff or one map bit (20 alternatives) each iteration, take the strict lexicographically best improvement, prefer the original coordinate order on ties, stop at a local optimum or 32 iterations. For E maximize number of valid correct episodes; for EC maximize that then minimize total successful rounds; for I maximize number of exact local actions. Deterministic teacher labels in I include a terminal STOP. Record actual objective queries, policy changes and costs. E/EC never receive a local target or reference step count at training.

Test. For standard unconstrained W=8 enumerate all 65,536 operand pairs with learned hard decisions and exact arithmetic (memoize equal readout/policy as needed). On variable layouts use all 4^8 *ordered* pairs of 8-column bank tag sequences (65,536 complete metadata layouts); use dynamic programming, only from actual graph reachability, for independently minimal length and validate every policy move, timing and STOP. Also enumerate all 4^7 layouts at unseen W=7 and evaluate a fixed set of 2048 held-out random layouts each at W=1,5,9,12 (seed 20263199) incl both lane phases, plus one readable-port ablation by flipping one bank tag on otherwise identical width-eight input. Report valid completion, optimal length, and exact demonstration matching separately. Layouts are independent of operand values; other than the explicitly exhausted flat path and audited combined tests, do not claim to have enumerated every combination of operands and layouts. Arithmetic cost depends on stride, and a controller decision and a terminal STOP add work beyond round count.
