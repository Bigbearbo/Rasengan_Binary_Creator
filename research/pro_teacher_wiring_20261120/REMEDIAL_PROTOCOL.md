# Exploratory paired remediation test, before study execution
Borrow student on the same original S1 board, four parameters, three known ports, final-only identity STE for 256 full-batch SGD updates at 0.25. Use 64 fresh seed values 20261201+i, i=0..63, with 64 distinct random byte pairs each. Trigger remediation only by imperfect training endpoint scores. Clone each triggered student to three 32-update arms: continued final labels; for each endpoint error, teach the first incorrect borrow step on that example; or for each endpoint error, teach one uniform random step. Examples with correct endpoints retain final-label supervision. Each student always reads its own predicted register. One selected target per example with gradients propagated from that step through time; batch denominator 64. Each arm independently selects from its own errors. Record extra monitoring costs and actual hints. Then train all triggered arms for 64 more endpoint-only updates with no step hints. Keep already successful original checkpoints as references. Evaluate all 65536 ordered inputs and full eight-step sequences at 256, 288 and 352, plus old S1 regression. This tests removing a learning hint; autonomous inference still takes eight bit rounds and does not test actual reduction in computation rounds. Do not select or tune on exhaustive scores.
