# Removing the teacher wiring scaffold on a recurrent binary student

Protocol before training. Freeze the original S1 19-unit adder. Extract the signed nonzero semantic ports of the added handfilled borrow gate from the previous verified model's matrix. Randomly permute the student's physical input columns per seed and resolve the transmitted port roles rather than copying coordinates. Student: 18 old board bits, private predicted borrow and bias, initially zero. Training labels: only final unsigned A < B. Uniform samples of 64 different ordered byte pairs per seed, seeds 20261120..20261135, paired across arms as in PR137. Hard zero-one forward, full eight-step identity STE, batch SGD rate 0.25, exactly 256 updates. No teacher at inference.
A has all ports open for every update. B uses only teacher ports plus free bias for updates 1..64, followed by all inputs open. S is B plus the teacher signs imposed only in those first 64 updates; bias free. C uses a seeded blind port per operand byte plus the same feedback and bias for the early phase, then all inputs. F uses the unsigned teacher ports and bias throughout; verify the previous restricted-port baseline. A/B/S/C therefore share the same final trainable graph. The task is the borrow trace and final comparison, not a full subtraction answer. Report checkpoints at updates 0, 64, 256, all training IDs and port maps, original nine-bit sum and stop, and entire-sequence as well as endpoint accuracies over all 65,536 ordered pairs. Include all outcomes. The exhaustive scores do not determine stopping or hyperparameters. No claim of automatic growth, external SLE decoding or distillation of the entire adder.
