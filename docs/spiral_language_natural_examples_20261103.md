# 螺旋語：自然語言寫法範例整理

整理日期：2026-11-03  
範圍：以 2026-11-01～02 討論的「有骨架的自然語言」為主，兼收同時期 AI 擴寫出的示例。  
性質：歷史例句與研究範例集；**不是新的正式語法規格**。
校訂：2026-11-03，依使用者與 Claude 討論的補充，修正「句號」職責混寫。

## 閱讀說明

這份資料分成三種來源：

- **U-原句**：可從先前對話檢索到使用者直接說出的語句，保留原來詞序及主要字面。對話檢索可能只保存局部片段，不能視為完整逐字對話備份。
- **U-概念／整理**：使用者提出概念，但下列形式是整理時用一致排版重述；不可冒充原話。
- **A-示例**：先前 AI 提出的候選寫法、演練或原型測試格式；不代表使用者已核准，也不代表符合正式位元編碼。

逗號、箭頭 `→`、分隔號 `｜` 與換行多半是方便人閱讀的表示法，**不可直接認定為螺旋語必備字元**。**依使用者 2026-11-03 最新澄清，基礎「句號」只負責句子結尾；其數量用於判定該層結束。** 不能把 `CUT`、任意返回、改變語境、降層命令等獨立功能都算成「句號」的固有職責。若確有類似結束或控制功能，可研究同詞根但**不同詞碼**的「句號親戚」。這裡未替任何親戚詞決定碼位或精確語義；也不把不同版本的 AI 原型當成正式規格。

## 一、使用者提出的自然語言寫法（按概念分組）

### U01｜沒有固定二元限制的加法

**自然意思：**「加」後面可以是一串數學實體；不必為每一對數字額外重複一次加法運算。

**U-原句（2026-11-01）：**

```text
加 → 1 → 2 → 3 → 4 → 5 → 句號
```

**另一個 U-原句：**

```text
數學 → 句號 → 加 → 1 → 2 → 3 → 句號
```

**研究整理（U-概念，非逐字）：**

```text
數學 → 加 → A → B → C → 句號
```

關鍵：語境可以在上層先宣告；「加」是概念算符，而不是必然只能收兩個參數。運算元的型別、求值時機仍需定義。第二例中靠近「數學」的「句號」，仍按當時的層級／結束數量規則理解為結尾標記；**不應額外推論它能執行通用「降層」或 `CUT` 控制指令**。當時的逐層計數與實際詞碼仍須從原規格另行核對。

### U02｜普通運算與命名運算可以並存

**自然意思：**在「數學」描述裡插入一個操作模式，例如「命名」或「普通」，而不必破壞早期單純的數學句子。

**U-原句（2026-11-01）：**

```text
數學，命名，句號。
新算符，算符a，算符b，句號
```

```text
數學，普通，句號。
新算符，算子們，句號
```

**U-概念／整理：**

```text
二層：數學 → 命名／普通 → 句號（此層結尾）
一層：新算符 → 構成算符／資料 → 句號（此層結尾）
```

補充判準：使用者也指出原本的「數學，句號」可以保留；新模式只是插入描述詞，不代表舊寫法立即失效。前版整理在這裡將句號直接改寫為「降層」，**已撤回該混寫**：層級之所以在結尾後改變，屬整套解析規則的結果，不能逕稱「句號」具備獨立降層指令的語義。

### U03｜數學描述的結果，仍可當作數學實體

**自然意思：**一個數學子句算出的結果，可以成為另一個數學式的輸入。

**U-原意片段（2026-11-01，保留搜尋所得措辭）：**

```text
數學，…句號，回傳是一個數學實體，可以用數學（數學，數學）
```

**U-概念／整理（括號是排版輔助）：**

```text
數學 → 乘 → 數學(加 1 2) → 數學(加 3 4)
```

這個示例強調「描述可以組合描述」，並非宣告括號是正式位元結構。還須分清數學實體是「已求出的數值」還是「尚待求值的運算式」。

### U04｜「後面有兩個句號」本身是一個詞

**自然意思：**用一個結構描述詞提示解析端，後續結尾數量與結構的預期關係。這個詞不是基礎「句號」本身。

**U-原句（2026-11-01）：**

```text
數學，後面有兩個句號，數學，數學
```

**重要原意：**「後面有兩個句號」是**一個完整詞**；不是連寫兩個句號，更不是把句號擴充成任意功能控制碼。依 2026-11-03 新澄清，若此完整詞具有基礎句號以外的「預告／結構描述」意義，須視為不同詞碼的候選「句號親戚」；不能偷偷共用基礎句號碼。

需進一步確定：這個「預告」詞如何與原有「句號數量對應層結束」規則配合，深層巢狀時如何計數，以及詞根可否組合出更多同族詞。**基礎句號的職責已受限；新詞實際語義與 0/1 詞碼仍未定案。**

### U05｜「說話者」可以是高層描述，也可以放其他層

**自然意思：**句子可直接附上誰在說話、誰被引用，以及某個人是否只是假想角色；可用來教陌生 AI 分辨真正學生 A 與教師扮演的學生 B。

**U-概念，對話提過的字詞：**

```text
說話者，教師，學生A，假想學生B
```

**U-概念／整理：**

```text
說話／代號 → 二層語言類別 → 一層內容
```

這是一種可選的三層放法，**不是強制所有說話者都必須在三層**。使用者後來明確允許說話者放一、二、三層，只要可解析且語義不衝突。

### U06｜問號是句子的一部分，不只是外部訊息

**自然意思：**「這個數學題是問題」可以直接寫在該句內，並可標記誰出題、誰回答。

**U-概念／整理：**

```text
數學 → 加 → 1 → 2 → 3 → 問號
```

這裡的完整詞序由整理者將使用者的語法原則具體化，**不是已核實逐字原句**。問號、發話者、回覆與批改的最終關係仍待正式規定。

### U07｜「啥意思？」可以是索取更多例子的學習行為

**U-原句（2026-11-01）：**

```text
啥意思？
```

**自然意思：**「我還沒懂，請再用別的方式說明，或者多給幾個例子。」這不是必須當成單純錯誤，亦可是一個學習請求。

### U08｜自然語言版螺旋語：領域、原則、否定對照

**U-原句（2026-11-02）：**

```text
領域，螺旋語實作到自然語言，原則，句號。
不只是，螺旋語版本，加標籤，底層螺旋語化
```

**自然意思：**討論的領域是「將螺旋語實作於自然語言」，後文提出的原則並非只替文字加版本標籤；底層語法、語義、儲存與操作也應該真正螺旋語化。

**U-概念／分層整理：**

```text
領域 → 螺旋語實作到自然語言
    原則 → 不只是「替螺旋語版本加標籤」
            而是「讓底層機制也螺旋語化」
    句號
```

這個樹狀展開是整理者的解讀。使用者原話並沒有逐詞指明「而是」和所有隱含階層，也沒有宣布這是完整機器語法。

### U09｜詞的選擇：清楚比過分簡寫重要

**U-原句（2026-11-02）：**

> 這個就是你自己的版本了，你選好你能讀懂或常用的詞，不一定要太過簡寫反而意義不清，你考慮就行。

意義：當 AI 自己開發其自然語言式記憶格式時，可以選常見、好理解的詞，不必為短碼而犧牲語義清楚。這是給 AI 設計自主權，**不是同意某一版 AI 詞表已正式定案**。

### U10｜有用的領域標籤與過度造詞的區別

**U-原話（2026-11-02）：**

> 比較有意義的概念才提出來，不然原本句子就行了。

> 討論領域區分本來就是有用標籤，紅蘋果我們又不是研究蘋果或顏色的，拆開就沒啥用

**自然意思：**不要為了展示「構詞能力」硬將每個熟悉詞語拆成子詞，也不要把每個組合都提升成獨立碼。應看概念是否能增加辨識、操作或重用價值。

### U11｜同一個字詞會因領域不同而有不同意義

**U-概念／整理（2026-11-02 討論）：**

```text
領域 → 數學
    加 → 1 → 2 → 句號

領域 → 文字
    加 → 「甲」 → 「乙」 → 句號
```

預期的兩種理解分別為數學加法與字串連接。**這是對當時討論的 AI 整理示例，不是使用者寫過的逐字詞序，也不表示兩個領域已正式共用同一算符碼**。

### U12｜同一意思可以有不止一種合法寫法

**U-概念／整理：**

```text
加 → 1 → 2 → 句號
數學 → 句號 ｜ 加 → 1 → 2 → 句號
數學 → 普通 → 句號 ｜ 加 → 1 → 2 → 句號
```

這組是將 U01、U02 與使用者「同一件事可有多種寫法」的判準合併展示，不是三行都曾被使用者原樣說出。`｜` 僅作人工標示不同層的接續，**不是額外詞，也不是將句號變成獨立降層指令**。合法的前提仍是各版本有清楚的句號數量、詞典與層級解析規則。

## 二、先前 AI 寫出的自然語言範例（A 類，不回填為使用者原話）

這組可直接供後續討論、解析器原型及回譯測試參考，但不能混為 U 的定案形式。

### A01｜具身分與引用的數學句子

來源：`/倉鼠世界/螺旋語_跨模型純01實驗/` 相關概念協議 v0.1，2026-11-02。

```text
數學｜加 1 2 3 ?
學生A｜引用｜數學｜加 1 2 3 ?
學生B｜假想｜數學｜加 4 5 ?
對話｜啥意思 上一句 句號
```

自然意思：第一行是問題；第二行標記學生 A 的真實話語被引用；第三行是教師使用的假想學生 B；第四行是在請求解釋上一句。標記身分不等於密碼學證明。

### A02｜多層數學子式與 `SUB` 結構詞

```text
數學｜乘 SUB(加 1 2 句號) SUB(加 3 4 句號) 句號
```

自然意思：計算 (1+2)×(3+4)。`SUB` 是該 AI 原型另造的單一結構詞，括號只是閱讀輔助；**不是 U04 的「後面有兩個句號」已被正式改造成 `SUB`**，也不可拿 `SUB` 的進入／返回子式行為擴充基礎「句號」的職務。

### A03｜命名函式再呼叫

```text
數學｜命名｜F 加 變數A 變數B 句號
數學｜F 3 4 句號
```

自然意思：先定義 F(A,B)=A+B，再呼叫 F(3,4)。

### A04｜巢狀列表或配對

```text
數學｜配對 1 SUB(配對 2 SUB(空 句號) 句號) 句號
```

自然意思：建構一個以配對與空值形成的兩元素結構。此例只證明候選語法能展示該構想，不等於已實作 ICFP 2020 的全部功能。

### A05｜版本更新命令的可讀示例

```text
版本｜二層n=5 一層n=6 句號
```

自然意思：以當前已知規則告知接收端下一版詞長變化。若舊端不理解版本命令，不能因文字可讀就認為它必能解碼。

### A06｜上下文繼承與局部不同詞義

來源：`/AI研究記憶/螺旋語與MLP.md`，SL-0.4。

```text
語境 → 詞典甲（JOIN=OR） → 開始區塊
    數學 → JOIN → 1 → 1 → 句號
    語境 → 詞典乙（JOIN=XOR） → 開始子區塊
        數學 → JOIN → 1 → 1 → 句號
    結束子區塊
    數學 → JOIN → 1 → 1 → 句號
結束區塊
```

自然意思：相同字詞 JOIN 在甲、乙下分別按 OR 與 XOR 解釋。內層結束之後要恢復甲。這是 A 的**語義模型**，不是已確立的層階詞碼；其中「開始／結束區塊」並非基礎句號自帶的語境切換功能。

### A07｜封存引用與重新求值

來源：`/AI研究記憶/螺旋語與MLP.md`，SL-0.3。

```text
引用 → 原句「F(1,1)」 → 依據語境甲保存
求值 → 這份引用 → 使用保存語境
求值 → 這份引用 → 使用目前語境
轉譯 → 這份引用 → 目標語境乙
```

自然意思：將「當初怎麼解釋」與「今天用新詞典怎麼解釋」分開，避免歷史資料被新版本悄悄改義。

### A08｜自然語言版的記憶紀錄（直接式 SNL R02）

來源：`/AI研究記憶/螺旋語記憶_平行實驗/` 下的 `自然語言螺旋記憶_R02_直接寫法.snl`。

```text
領域，螺旋語記憶。
語境，SNL R02，AI 自選自然語詞，2026-11-02。
原話，使用者：「這個就是你自己的版本了，你選好你能讀懂或常用的詞，不一定要太過簡寫反而意義不清，你考慮就行。」
AI解讀，作者把選詞決策交給 AI；可多字詞，優先清楚易讀，避免過度縮寫引入歧義。
不能推出，使用者已確認本 R02 詞表是螺旋語永久正式詞典。
句號。
```

自然意思：把人類原句、AI 解釋與「不能據此推出的結論」分開存。這份 SNL 格式是先前 AI 自製的平行實驗。

### A09｜自然語詞的巢狀概念組合

來源：`作者原話_概念組合示例.snl`（內容為 AI 根據 U08 重述）。

```text
領域，螺旋語實作到自然語言
    記憶，U001
        原則
            對照
                不只是
                    加標籤，螺旋語版本，句號
                句號
                而是
                    底層螺旋語化，記憶系統的語法、語義、存取與運作，句號
                句號
            句號
        句號
    句號
句號
```

自然意思：將「不只是／而是」寫成結構性對照，不把整個命題藏在一個普通長字串中。這個縮排形式是節錄、便於閱讀，不等同正式位元對映；**其重複「句號」只是 SNL AI 原型的封閉寫法，不能當成 U 對基礎句號的正式定義**。

### A10｜由既有概念合成新詞，再重複使用

來源：`新詞組合與重用.snl`，SNL-MEM v0.2。

```text
定義詞，底層化原則
    對照
        不只是
            加標籤，螺旋語記憶版本，句號
        句號
        而是
            底層螺旋語化，詞語組合、層級作用域、語義操作、版本引用，句號
        句號
    句號
句號

語境，2026-11-02
    領域，螺旋語實作到自然語言
        記憶，U002
            原則
                用詞，底層化原則，句號
            句號
        句號
    句號
句號
```

自然意思：先組合一個可重用概念詞，再讓後面的記憶引用它。但生成新詞是否值得，仍要服從 U10 的判準：不能為了造詞而造詞。

### A11｜詞典槽號重用與歷史語義

來源：`/AI研究記憶/螺旋語與MLP.md`，SL-0.11。

```text
群甲@R7：槽42，世代1，函式 JOIN
群甲@R8：刪除槽42 → 留墓碑，世代1；其他槽號不移動
群甲@R9：重用槽42，世代2，函式 CUT
舊引用 (R7, 槽42) → 仍為 JOIN
新引用 (R9, 槽42) → CUT
```

自然意思：保存歷史引用，不因為刪掉舊詞、重用編號就改寫舊記憶。這是 AI 的後續版本研究例子，與原始「自然寫法」同屬語言可演化的研究，但不代表已成正式語法。

## 四、這批例子的共同設計原則（整理，不是新規格）

1. **像自然語言，但要有可解析的骨架。** 不是把任意中文加上標籤就等於螺旋語；概念、層級、作用域、語義操作和更新必須有實際機制。
2. **同一意思可以有多種合法表示。** 平坦、巢狀、具名、不同層級的寫法可以競爭或並存；但各版本自身的切詞與解讀須明確。
3. **新詞與舊詞組合並行。** 可用未使用詞碼或擴階新增功能；也要考慮是否可以先用已有的概念組合，避免詞典失控膨脹。**同一詞根可以產生職責相近、但獨立編碼的詞族；不能因語義接近就共享同一碼並暗改既有詞義。**
4. **詞典、語境與版本不可忽略。** 一句可讀的「加」不能在任何領域都自動解成同一函式；舊話也不該被新版靜默改義。
5. **先有機制，再談壓縮與效率。** 自然語言範例只顯示可能的語義，不代表位元解析、跨模型學習、真實記憶效率已驗證。
