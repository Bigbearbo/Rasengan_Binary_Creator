## 1. 實際教了什麼

使用固定 k1／n5 profile：每詞五個資訊位加尾零，普通符號 ID0..29；END=`111100`、UP=`111110`保留。Q 為開場01、回音算符010、四 bit 的 r 欄、N個符號、END；A 是前 r 個完整符號，學生自行生成 STOP。010在這個隔離 profile 中使用，不混用舊 Neg 映射。符號是待複製內容，不執行其可能代表的算術。

既有 P030 Model 的科學碼保持原樣，L80/H64、10,499參數，Adam0.003與原梯度截限不改。三個新學生 seed101／202／303由隨機初態開始，沒有移植舊學生或人工 copy 權重，也沒有 grow。raw Q與答案前綴以原兩通道位元介面輸入；自主生成只接自身輸出，不另給 r、詞界、答案長度或 cursor。

Qmax39、Amax24，正確作答連STOP需25動作；本輪新runner固定cap32，最長可能送入模型的prefix70，放得下L80。宿主只在模型輸出STOP或到固定cap時停止，沒有按r截斷。

每輪將全部教師target洗牌一次，保留精確多重集合；不是逐題連續更新答案所有位置。權重、moments、更新年齡跨階段延續。N1題各曝光56輪、N2各32輪、N3各24輪、N4完整回音各16輪、N4部分回音各8輪；各位置和不同 r 的有效曝光並不相等。

資料含750訓練題、360測試題。N1覆蓋全部30符號；N2／N3／N4各120個訓練payload和60個測試payload，每位置每ID分別出現4／2次。同一完整payload的各r留在同一split。固定例題 `[1,6,11,17]` 排除於這一批，1,110個Q與17,490個teacher prefix皆不同且無矛盾標籤。

沒有validation、early stopping或分數決定的追加教學。全部初態與五個階段末都先存檔；三條主訓練與指定重播結束後才統一評分。早期報表另分已教題與還未教到的最終題庫，避免把未來題目說成已教失敗。

N4主測的資訊位（排除每詞固定尾零）自主生成正確率合計 **6,861/9,000＝76.23%**；餵正確答案前綴的teacher forcing為 **7,713/9,000＝85.70%**。正確前綴下仍有不少內容錯誤，所以不能只歸因於第一個錯字造成後續連鎖。自主生成又更差，表示實際生成狀態也帶來額外損失；這些行為數字尚未唯一識別內部原因。

## 3. 課程限制與能力退化

這輪是固定課時的漸增課程，**不是先學會再升到下一階**。第一階結束時，三學生一詞已教題各11/30、9/30、30/30；兩個學生沒有打穩這個基礎便按固定預算前進。這是本輪Pro設計的限制，不能把後續失敗宣稱成「逐階掌握後仍不可能擴展」。

另一方面，seed303第一階已30/30，後面仍退化；因此首階未達標也不是唯一已證實的病因。四詞階段結束時，N4完整測試三學生皆0/60，已教僅0/120、0/120、1/120；長內容複製在加入count contrasts之前就未學好。

最後一階同時包含新增count題與93,840次額外更新；本輪沒有等曝光的完整回音續訓對照。可確認這段時序後的退化，尚不能把count語義、共同參數干擾、學習率、optimizer年齡或較短題權重分配中的任何一項判為唯一原因。

## 4. 曝光界線

測試是未教的完整payload題目組合，並非所有內容角色都未出現。N2測試60個payload中，11個曾是更長訓練payload的前綴、21個曾是其連續片段；N3分別0／1。N4的r1答案全都曾作完整訓練答案；r2有18/60曾完整出現或作答案前綴；r3與r4在這兩個曝光類別皆0/60。詳細來源ID保存在固定資料和結果曝光子群中。

因此 r1表現好不能單獨當成任意新內容copy證據。對r3／r4較長輸出，仍只有16/180、3/180整題正確；同時所有普通符號在各訓練位置皆有覆蓋，不是把未見符號當成主要盲測。
