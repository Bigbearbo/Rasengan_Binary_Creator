## 開始前先填這一張

| 欄位 | 寫下具體內容 |
| --- | --- |
| 本輪問題 | 哪個尚未被證據分辨的問題，會改變下一步決策？ |
| 已有依據 | 實際來源 commit、結果／原碼路徑；已做過哪些類似試驗？ |
| 學生起點 | 真正最後 checkpoint 或明示的重新初始化；權重／optimizer／RNG 版本 |
| 唯一主改動 | 資料、課序、格式、架構、學習率或其他哪一項？多項一起改時只比較整套政策 |
| 相應對照 | 從相同起點、同語義工作量或主要預算軸比較什麼？無對照就標描述性續訓 |
| 教材支援 | 獨立題數、角色與 bit／組合曝光，標籤、STOP、prefix、mask 的實際輸入 |
| 成本與停止 | 有限更新／MAC／時間預算，量測點，實作失敗條件；分報額外推論與重試 |
| 主要指標 | 自由生成完整答案含 STOP，逐課／逐 seed；升課門檻和研究成功判準分開 |
| 泛化範圍 | 已教題、新完整 Q、新相關組合、新角色、新值或新長度？各自有沒有起點？ |
| 保存與交接 | 完整狀態、資料／課序、程式、失敗、原始回答、執行收據與下一個負責人 |

若已有規格與驗證，引用它而不重新抄寫。只有相關部分改動或出現具體異常時才追加工程檢查。新研究按適用規格在訓練前固定上述選擇，不把事後補寫冒稱事前設計。

## 三種分數，三種用途

| 觀察 | 主要用途 |
| --- | --- |
| 自行生成的整串答案與 STOP 全對率 | 回答模型在實際介面能完成多少題；報 correct / total |
| 教師正確前綴下的 loss／位元率 | 定位學習與生成差異；不代替完整生成能力 |
| 分角色、位置、長度的錯誤／停止／cap | 找下一個有資訊量的對照，不只追一個平均數 |

95% 不是通用法律。4、8、16 題時，至少 95% 仍是全部答對；用來估計能力時要看分母和覆蓋。若主要目的是比較方法，可用固定預算加完整曲線，將達到 90／95／99% 的成本列為摘要，不必把其中一條設成所有後續工作的硬門檻。

## 依症狀只選一個有用動作

| 症狀 | 優先動作 |
| --- | --- |
| 很多訓練次數，幾乎沒學到 | 先核對實際見過幾種題、是否卡在少數題；P027 有直接案例 |
| 新程式連幾道一致小題都擬合不了 | 獨立診斷狀態檢查輸入、label、gradient、update；小批全對是除錯用途 |
| 訓練高分，未教題差 | 分清角色／數值／組合的教材支援，再選要測的遷移問題 |
| 自生差、正確前綴好 | 先確認模型是否真的讀前綴內容，再查首錯、早停與回饋 |
| 擴網後新格式差 | 分量同 raw 函數保持、換碼立即表現、再訓練恢復成本 |
| 新課上升、舊課下降 | 保存逐題對→錯與錯→對；看是否恢復，再比較有限複習政策 |

## 成長與比較時容易漏掉的事

網路長大和資料詞變長是兩個變項。保持 logits 不等於保持換碼後的能力；搬運權重也不等於搬完整 Adam 狀態。新單元全零可能無法啟用，要確認它有學習途徑。

複習舊語義的當前格式、回教舊 raw 格式、測歷史版本相容，三者分開。依原任務決定，不用這張卡推翻歷史條件。

等題數、等 target 更新、等 MAC、等時間並不相同。native 編碼輸出較短時，成本差可以是系統效果；說明比較軸即可，不必用人為補長抹掉差異。對照也保留穩定 ID、局部擴階及合理成長權利。

末階追加成本與全程總成本一起報；若生命週期要提供各階能力，終點從零模型不一定完成同樣工作。失敗 seed、達標前消耗、調參搜尋與評估成本均保留，沒有計數就標未知／有界範圍。

## 結束時留下可繼承的經驗

| 欄位 | 記錄方式 |
| --- | --- |
| 原先預期 | 事前預期哪種結果，為什麼 |
| 實際執行 | 命令、環境、時間、資料／程式／狀態版本，真正更新與推論數 |
| 原始結果 | 每 seed、每課曲線、真正最後 state；另列 best，不相互替代 |
| 能下的結論 | 與對照及資料範圍相符的結論 |
| 仍不能下的結論 | 無起點不稱改善，無對照不稱因果，已見值新 Q 不稱全新值 |
| 失敗與修正 | 保留錯誤、額外消耗、修改位置；不能把修後成功回填為原版一次成功 |
| 下輪最小問題 | 指向一個會改變選擇的問題，避免重複同一種 probe |

來源一律分 U／F／T／A，T 加執行者和日期。文獻學到的方法、前輪實跑的成果、本輪新測到的結果分開；後來的解釋不回填為最初預測。
