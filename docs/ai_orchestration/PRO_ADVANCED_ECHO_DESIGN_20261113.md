## 1. 題型定義

名稱採「多詞回音」，獨立 profile 為 `SLE-AE1-n5-v1`。初版只用一層 k=1，符號資訊寬 n=5；每詞為五個資訊 bits 加一個尾零，共六 bits。每題有 N 個符號，參數 r 表示**要回覆前幾個詞**，固定 `1 ≤ r ≤ N ≤ 4`。

| 欄位 | 編碼／規則 |
|---|---|
| 開場 | `01` |
| 多詞回音算符 | `010`，本獨立 profile 的示範分配 |
| 回音詞數 r | 三個資訊 bits 加尾零；r=4 為 `1000` |
| 待回音符號 | n5/k1 的普通 ID 0…29；依出現順序複製，不執行其算符含義 |
| 句號 END | 此符號串詞典的倒數第二碼，ID30=`111100` |
| 升階 UP | 此符號串詞典的最後一碼，ID31=`111110`，本題型不使用 |
| 正確回覆 A | 前 r 個完整符號，保留每詞尾零；不回題頭、參數或句號 |
| 輸出結束 | 神經學生另外自行選擇 STOP；它是既有輸出動作，不是 01 語詞 |

P030 舊算符 `010` 代表 Neg；這裡採使用者的假設碼作獨立題型示例，不覆寫舊映射。本輪不把未標記的新舊 profile 混在同一學生題流。正式混教時需分配不衝突的詞碼或使用學生可見的版本結構，不能靠宿主標籤暗中區分。

數值參數欄位與符號串詞典分開。END／UP 的保留限於這個符號串欄位，不表示其他數值資料域全面禁用 30／31。只在已知六 bit 詞界識別 END，不搜尋任意 bit 子字串；符號內容出現較短的 `100`、`110` 不會提前結束。

## 2. 四個五階詞的完整例子

取符號 ID `[1, 6, 11, 17]`，回音詞數 r=4。下列空格只供閱讀，送給學生的仍是連續 0／1：

```text
Q: 01 010 1000 000010 001100 010110 100010 111100
A:             000010 001100 010110 100010
```

生成完 A 後，學生還需輸出 STOP。這四個詞的資訊欄位合計 20 bits，答案連同四個尾零為 24 bits。保留兩個控制 ID 後，四詞有 `30^4 = 810,000` 種有序組合（允許重複符號）；這是合法題域大小，不是要求全部拿來訓練或聲稱本輪已檢查全部。

這個構想的價值在於可以產生很多不同的複製內容和輸出位置。更長輸出也增加出錯機會，因此不能預先宣稱大網路教長題反而一定更容易。首先要測的是更多樣的合法例子能否導出可轉用的回音行為。

## 3. 教學次序與參數是否真的有效

第一段採使用者的完整回音：固定 n=5，依序由一詞增加到四詞，教材只取 r=N。單詞階段可覆蓋全部 30 個普通符號；多詞階段增加不同排列、重複符號和位置交換。先固定詞寬，只增加詞數，避免同時改變兩種長度。

**只做 r=N，不能證明學生有讀參數。** 它可以忽略 r，照抄到句號仍然全對。這不否定完整回音的價值，但需要另外檢查參數功能。

第二段是 Pro 的 A 延伸：同一串四個符號分別搭配 r=1、2、3、4，要求只回前 r 詞。r 從第一段起就定義為回覆詞數；第二段只是解除 r=N 的教材限制，沒有中途改義。

| 相同題內符號 | 參數 r | 應回覆 |
|---|---:|---|
| 1、6、11、17 | 1 | 1，然後 STOP |
| 1、6、11、17 | 2 | 1、6，然後 STOP |
| 1、6、11、17 | 3 | 1、6、11，然後 STOP |
| 1、6、11、17 | 4 | 1、6、11、17，然後 STOP |

這四題的總輸入長度、payload 和 END 相同，只有參數不同；全部答對才比單一長度更能支持參數控制了回覆。生成器不得按 r 截斷答案、代發 STOP，或把解碼後的 r／詞界／預期答案長度另餵給網路。教師 codec 只能產生教材與評分標準。

正式學習時應把完整符號序列作為分組單位，同一 payload 的各個 r 版本放在同一資料分割，避免只換參數就稱為新內容泛化。應另報已教組合、未教排列、參數配對成功率與完整 STOP 正確率。若之後研究未教長度，必須另外設計保留長度的對照，不把逐階已教到四詞說成四詞零樣本成功。

本輪還沒有固定訓練／驗證／測試題單、三 seed 課序、更新預算或停止門檻，因此不是正式訓練的事前登記。下一棒應先把這些項目凍結，保留全部學生與固定測點；不用本文件的人工範例作新盲測成績。

## 4. 現有網路放得下，生成上限需要調整

F：[現行 UR1 learner](../../experiments/spiral_neural/20261113_pro_notice_learning/learner.py)是 L80/H64、10,499 參數，生成 cap24 包含 STOP。AE1 初版可沿用同一模型類別與尺寸，另建新學生；不把 UR1 權重或前輪人工 copy 權重默認移植進來。

Q 長度為 `9 + (N+1)×6`，A 長度為 `6r`。對四詞完整回音：

| 項目 | 精確預算 |
|---|---:|
| 題目 Q | 39 bits |
| 回覆 A | 24 bits |
| 正確回覆連 STOP | 25 個生成動作 |
| 最後 STOP 預測時的 Q+A | 63 個輸入位置 |
| 建議事先固定的安全生成 cap | 32 個動作，含 STOP |
| cap32 內即使一直答錯，最長送入 forward 的 prefix | 39+31=70 個位置 |

所以 L80 有餘裕，**原 cap24 卻不可能完成 24 bits 再 STOP**。新 AE1 runner 應獨立採 cap32，不改寫原 UR1 的凍結程式或歷史分數。cap32 是上限，不是由宿主強迫回答指定長度。

若以後只增加詞寬而維持 N=r=4，正確最長 prefix 一般式是 `9+9(n+1)`：n5 為63、n6 為72、n7 為81。n7 已超過 L80，且答案連 STOP 需33動作；屆時才需另設容量／生成預算。這只是資源推算，未實作跨寬度教學，也未處理多版本混教。

## 5. 前綴一致性與本輪程式證據

固定 AE1 profile 中，合法 Q 彼此不成真前綴：較短題目的 END 不可能在較長題目的相同詞界充當普通符號，因 ID30／31 在此符號串保留。不同 r 又在固定長度參數欄位直接區別。因此不同題目接上各自答案前綴時，不會僅因題尾與答案相接，產生相同 raw prefix 卻要求不同教師 target 的歧義。

這個論證只適用固定 n5、固定欄位的 AE1。它不保證任意新舊 profile 混教都無碰撞；歷史 P030 跨階段原本就有不同教材對同一 raw prefix 改標籤的案例，不能混為本輪文法自相矛盾。

新程式與實際檢查入口：[AE1 codec／fixtures／checks](../../experiments/spiral_neural/20261113_pro_advanced_echo/README.md)。固定完整例子、同 payload 不同 r、普通符號與控制碼邊界、非法封包拒絕、輸入／輸出預算及小字母表的跨題 prefix 標籤一致性都以程式核對。這些是編碼與教材正確性的 T，並非神經學習成功。

Pro／受指派 agent 本輪實際執行一次 PASS：四個固定 raw 例題、30個普通 ID 在四位置的120案例、42個非法案例拒絕；小字母表 `{0,1,29}` 的426題，90,525對完整 Q 無前綴關係，6,438個 teacher-prefix 無矛盾標籤。最大Q39、A24、prefix63、含STOP25動作與獨立算式一致。命令為 `python -B experiments/spiral_neural/20261113_pro_advanced_echo/check_design.py`；原有學生程式與checkpoint未改。
