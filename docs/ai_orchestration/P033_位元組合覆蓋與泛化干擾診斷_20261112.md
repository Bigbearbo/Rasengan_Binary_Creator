### 已見到的可重現現象

P032 2 splits × 3 seeds × H72/H128 × Neg佔70%/50%=24條分支；每分支對每個算符只見6個訓練數值，每個算符另有1val/1test，共12種已教 (op,value)；3000次新階題次實際重複這12題。四格 train 全部72/72（每格6個學生），val全0/12、test各0/12或1/12；加入Neg前 Echo test 24/24，後僅2/24。模型STOP位置對47/48，原資料輸出四位的位置自由生成 bit 正確為40/48、10/48、9/48、47/48：失敗集中在資訊位；注意 free-run 後續位可能受到第一個錯bit的級聯，需看已存 teacher-forcing 逐位logits分離。

這批排除了「只把 H72 擴到 H128」「把70:30改為50:50」作為這兩組分割的可靠解法，**沒有證明網路容量永遠不重要**。加入Neg前後 Echo Q raw和輸入位置完全相同，退步不是當階資料位移。

### 可由程式和位元表**確定**的教材缺口（本輪新分析，不是新模型實測）

```text
S0 train: 000 001 010 011 101 111
   val=100, test=110
   train當最高位=1時，最低位總是1
   val/test都是「最高位=1、最低位=0」，該pair從未出現在train

S1 train: 000 001 010 011 100 110
   val=101, test=111
   train當最高位=1時，最低位總是0
   val/test都是「最高位=1、最低位=1」，該pair從未出現在train
```

這兩個分割的驗證題和測試題不僅是「未見的單一數值」，還是同一種未見的**二位元交互組合**。在每個算符僅6個數值的情況下，完全可能學到「高位→低位」的錯誤捷徑而非無條件逐位copy/flip；**此機制在現有模型內部尚未被證實**。六個訓練值重複3000題不是3000個獨立組合，增加H與重複同題不能補上未觀測反例。

對照兩個 **6 train/2 holdout，所有2位元對組合均覆蓋** 的候選：
```text
C0 train: 000 001 010 011 100 111  (0,1,2,3,4,7)
   holdout: 101 110  (5,6)         [P030同家族舊分割，須視已研究]

C1 train: 000 001 010 011 101 110  (0,1,2,3,5,6)
   holdout: 100 111  (4,7)         [可獨立重開，仍是同一8值問題]
```
所有三bit的pairwise二元組合已覆蓋，但完整三位元組合仍有2個未見。C0/C1同樣不直接證明會學到Echo或Neg，只作**覆蓋消融**。這是一次可枚舉的數學結構差別，不應把 S0/S1 簡單評成「不公平測試」：它們恰好在測**結構外推**，只是不能代表所有保留數值。

## 1. 主要機制候選與需要拿證據否證的部分（A）

**H1｜位元交互捷徑（優先）**：模型學到例如高位=1→低位常數關係，因而在未見的高/低pair出錯。檢查同算符下改變Q的某一資訊bit而保留其它bit與已生成prefix不變，觀察對應答案位置的logits/correct_probability是否敏感。這是分析用的**反事實前綴**，不當正常合法題輸入評分。

**H2｜自回歸 teacher-prefix 依賴**：`p030_reference.Model.forward(q + previously_answered_bits)` 用**扁平 onehot 的完整 Q+正確答案前綴**預測下個輸出。由於已教值只有六種，網路可能依賴答案前綴統計，而不是學到讀取Q中對應位元的可組合運算。對比已存 `teacher_forcing` 每一位、首個錯誤位與自由生成後續錯位；測在輸出prefix保持不變時翻轉Q位的敏感度；不能僅由 free-run 中間位錯誤率直接確認它忽略Q。

**H3｜權重干擾而非全面遺忘**：Echo的已教六值始終答對，但添加Neg後未見的Echo正確率從24/24降2/24。追蹤同一Echo raw Q、同一target position在Neg前後的logits、決策邊際與隱藏激活變化；與「只有Echo再訓3000題」的等題次控制比較，分辨Neg語義特定干擾與普通後續訓練漂移。

**H4｜輸入位置／模型架構歸納偏好**：目前是 `L=16` 的扁平位置 onehot → 單層 `tanh` hidden → `0/1/STOP`，無明確學到「輸出第i資訊位→輸入第i資料位」的結構。這種表達可擬合已教序列卻未必偏好逐位演算法；但 **n3同Q的退步不是升階位置漂移**。需先完成 H1–H3 診斷，再比較小型可學位置對齊/注意力架構，不要先把固定解析器的位對齊或 oracle 答案提供給 NN。

## 3A. 作者新增假說：「題目混合著教」——從最初就交錯教，而不是後期才加新題型（U，2026-11-12）

作者問：「題目混合著教會不會好點？」需要保真區分兩種「混合」：

- **P032 已實測** Echo 單獨暖身四階（共1824題）後，加入 NegEcho，再以 **70% Neg / 30% Echo** 或 **50% / 50%** 混合訓練；兩種均沒有穩定挽救未見題。
- **作者現在可研究的新假說**：在**相同合法 profile** 首次開始學 Echo 與 NegEcho 時，兩種題型**從一開始就交錯出現**，而非先把 Echo 教到熟練再切換。這是 **interleaving from scratch**，不等於 P032 的新舊題比例調整。尚未實測，不能說已被 P032 否決。

理論動機（不是本案成效證據）：多任務神經網路文獻中，交錯學習有時減少連續任務干擾，但不是任何任務都優於分段學習。原文來源：https://research.google/pubs/multitask-learning-via-interleaving-a-neural-network-investigation/ 和 https://pmc.ncbi.nlm.nih.gov/articles/PMC6217400/；另有分段優於交錯的特定架構/任務例：https://pmc.ncbi.nlm.nih.gov/articles/PMC11332129/ 。

### 最小辨因實驗：教材涵蓋 × 教學時序 2×2

保持**原生 SLE 01 題目**；固定 `op2/data3` 同一版 profile（沒有 END）、H72、同一數值集和 SLE encoder，先**不引入升階、位移、翻譯器、神經元增長**，以防「早期只有 Echo 詞碼、後來擴位」混淆教學序列本身。

兩個教材分割：
- **G0**：S0 訓練值 `0,1,2,3,5,7`，保留 `4,6`，高低位 pair `10` 缺失，屬結構外推。
- **G1**：C1 訓練值 `0,1,2,3,5,6`，保留 `4,7`，兩位元 pair 全涵蓋，屬完整三位元組合外推。

兩種課程順序，用**完全相同的可訓練 (op,value) 多重集合／總題次／每 op 曝光／每值曝光／target-token updates**：
- **T0：分段**，先連續 Echo 題，再連續 NegEcho 題；並在最後可評估 Echo 保留。
- **T1：從頭混合**，Echo/Neg 等量或預先固定比例穿插，兩種題目從第1個完整 lesson 就開始交錯。
- 可加 **T2：小區塊交替**（例如每20～50題換算符，尚未熟練就切換），不改樣本集合；需要預先登記切換頻率。這可測「完全隨機混題」與「短時間內集中一種規律」差異，不必永遠二選一。

初始固定至少3 seeds（101/202/303）和同一初始模型快照；對每個相同 `(split,seed)` 的T0/T1由**同一張訓練多重集合重排順序**，不能讓 T1 無意間比 T0 多看到測試題。可選 2,000～3,000 筆固定訓練題次，題次與每題 answer+STOP 皆相同，所以成本可直接比較；最終訓練/holdout都報，且**階段中途**固定測點（如每100～200題）在每個算符所有8個數值上記 free-run（這些診斷值已被研究過，勿冒充新盲題）。

評估時**同時回答**：
1. T1 是否在同一 G0 或 G1 上比 T0 更擅長保留 Echo 與掌握 NegEcho？
2. 如果 G1 明顯優於 G0，而教學序列差別有限，則先補教材組合；若 T1 改善兩組，教學順序確有作用；若只有 G1+T1 成功，兩個因素可能互相配合。
3. 是否真的能泛化到未教值，還是 train 全對；要有逐位/首個錯誤位、teacher forcing、同題次MAC與參數記錄。
4. 若 T0 因為最後全是 Neg 而表現很差，T1 的優勢可能部分是**近期重複訓練效果**。因此可以追加 **T0B：Echo集中特訓 → 後期混合新舊（P032式）**，用相同總 exposure 和相同多重集合對照，避免只比較極端容易忘記的單一 block schedule。

**建議執行序**：先使用現成P032真值表及 P033-D counterfactual probe，之後把 G0/G1×T0/T1 的12條訓練當作**下一輪最小可實驗包**；不要同時擴大到128/256，否則難以拆分原因。若每100題分段測量既有保留集，不得用保留集做訓練時的超參數挑選。

## 5. 主線與驗收邊界

兩條學生仍共用 PR #5 的 SLE 題庫接口與版本規格；P033 NN 診斷不能把教師 oracle 放進 NN 推論路徑。P031的1,342題目前另起 P031 資料分割且**沒有用於 P032 訓練**，不可僅說「題庫已建好，所以P032失敗與資料無關」。對應問題是**實際教過哪些內容與哪些語義組合**，不是檔案有多少題。
