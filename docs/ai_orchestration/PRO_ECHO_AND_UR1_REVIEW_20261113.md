# Pro：回音能力、八位元學習與 UR1 最新進度

作者與本輪審查：**ChatGPT Pro／受指派 agent**。日期：2026-11-13（Asia/Taipei）。本輪以 Codex [PR #13](https://github.com/Bigbearbo/Rasengan_Binary_Creator/pull/13) 的 `15b7788c1d50269f477b0681d64cbbd08708d65f` 為固定來源。U 是使用者方向，F 是來源，T 是實際執行，A 是分析或未驗候選。本輪沒有新神經訓練；新增有界唯讀審核，以及一次人工權重的表達能力驗證。

**現有證據不支持把 UR1 的失敗直接歸因為「全連接網路很難做回音」。** 固定形狀回音可以由這類網路表示，歷史小網路亦實際學會過有限回音任務。現在尚未成功的是：目前純 01 介面、有限教材與訓練程序下，UR1 地址／寬度的未教搭配。這三個問題需要分開。

## 2. 「逐步到八位元」到底證明了什麼

F／歷史 Codex T：[P029](../../experiments/spiral_neural/20261112_p024_p030/reports/P029-論文四逐階不退回實測-2026-11-12.md)的資料資訊位寬 n 從 1 增加到 8，網路始終是 **1,171 參數**，不是邊教邊增加神經元。23 個輸入位置各有 `0/1/|` 三通道，16 個 tanh hidden，輸出為 0/1/STOP；每一步重新讀取 `Q + | + 答案前綴`，沿用權重與 Adam 狀態。[原始模型](../../experiments/spiral_neural/20261112_p024_p030/src/echo_prefix_direct.py)與[課程](../../experiments/spiral_neural/20261112_p024_p030/src/echo_monotonic_curriculum.py)可以直接核對。

n1–4 確實教完整 2、4、8、16 個值；n5–8 已有 train／validation／test 分割，依序為 24/4/4、48/8/8、96/16/16、192/32/32。不是每階所有值都拿來教。這是當階編碼的分割；相同數值可能先前在較短寬度出現。升階門檻 n5 起是 validation 整串及 STOP 至少 95%，連續三次通過；n8 的整數門檻為 31/32，並非所有八位元輸入 100%。

| P029 組別 | seed101／202／303 的 n8 test | n8 教學題次 | 全程 target 更新 |
|---|---|---|---|
| n1→8 逐階 | 32/32、30/32、31/32 | 960、768、768 | 33,850、24,712、24,708 |
| direct8 | 32/32、31/32、32/32 | 2,304、2,304、2,880 | 23,040、23,040、28,800 |

`direct8` 的意思是**從零直接訓練八位元教材**，不是未學即零樣本跳到八位元。逐階學生到達 n8 後所需教學較少；把先前七階也計入，總更新成本沒有三 seed 一致優勢。這些數字來自 [summary-table](../../experiments/spiral_neural/20261112_p024_p030/evidence/echo-monotonic-ranks-20261112/summary-table.json)、固定 plan 及六個 n8 曲線封存；本輪只讀既有結果，沒有重跑。

更直接的有限回音學習證據是 [P027](../../experiments/spiral_neural/20261112_p024_p030/reports/P027-修正教學方式與教材覆蓋-2026-11-12.md)：同一個 1,171 參數 MLP，固定八位元，192 個 train 值、64 個 heldout 值，CE 與無條件換題後三 seed 都達到 train192/192、heldout64/64，完整自由生成包含 STOP 全對。每 seed 是 20,000 次呈現、200,000 target 更新；固定 100,000 更新測點也都 heldout64/64。[P028](../../experiments/spiral_neural/20261112_p024_p030/reports/P028-學習所需題次與提前停止-2026-11-12.md)另測到達時間，三 seed 於 2,496／2,304／2,688 題次達標，heldout 仍全對。

這些八位元實驗帶有外部 `|`，不能直接當成當前純 01 UR1 的同條件成功；**也不能反過來認定「少了 `|` 就必然失敗」**。[P030 純二元結果](../../experiments/spiral_neural/20261112_p024_p030/reports/P030-純二元動態網路第一批結果-2026-11-12.md)已取消分隔符，九個學生仍完成短題 Echo 與算符擴位，後續才在混入新語義時出現更大困難。P030 的資料域、模型與課程又不同，不能由跨實驗差異獨立估出分隔符效果。

## 3. UR1 不是任意位置搜尋再重組

F：[UR1 codec](../../experiments/spiral_neural/20261113_pro_upgrade_notice/notice_codec.py)與[固定教材](../../experiments/spiral_neural/20261113_pro_notice_learning/dataset.py)定義：

```text
Q = 8-bit header + address + UP + UP + UP + END
A = address + UP
  = Q[8 : 8 + len(address) + len(UP)]
```

地址始於 zero-based 位置 8，也就是第九個 bit；count 佔四 bits，第一個 child ID 始於位置 12。m4/m5/m6 不改變地址在 Q 中的起點。地址深度會改變地址長度與 UP 起點，但 A 仍是一段連續摘錄。Pro 本輪用既有 `make_rows()` 非神經重建，18/18 都符合上述切片等式；Q 長 36–52 bits，A 長 13–23 bits。

例如 p0_m5：header=`00111100`，address=`00100000`，UP=`111110`，END=`111100`；回覆就是 `00100000` 接上一份 `111110`，沒有搬運數個分散片段。這也保留使用者 U 的局部確認與尾兩碼控制構想，不必複製整道題目。

A：仍需學習的是**每一生成步應讀哪個輸入 bit，以及何時停**。現在的 MLP 每步重讀 `Q + 已生成前綴`，沒有 recurrent hidden state，也沒有額外的 Q/A 分隔符、地址指標或答案 cursor。合法 0 的 onehot 是 `[1,0]`，padding 是 `[0,0]`，所以模型有總 prefix 長度線索；但不同 Q 長度下，相同總長度可能代表不同的回答進度。它需要從 raw 格式和已答內容學會對應關係。

同一套模型權重在各生成步重用，但不同絕對輸入位置有不同的連線列；架構沒有強制所有位置共用一條「複製第 j 位」規則。這是合理的學習難點，不是目前已隔離證明的唯一病因。全部六種地址、三種寬度皆在 train 出現；保留的是特定搭配，不是未知寬度 m7／m8，也不是無界長度外推。

UR1 有 12 個不同訓練通知，不等於只教 12 次。每個通知各呈現 128 次，每 seed 合計 1,536 次完整呈現、27,136 次 target 更新。每地址只有兩種訓練搭配，但不是只受教兩次。反覆曝光可以改善擬合，**不能保證把不足以約束規則的例子重複更多次，就一定得到未教搭配的正確行為**。

## 4. 本輪的人工構造只回答「能不能表示」

Pro T：[固定八位元回音構造](../../experiments/spiral_neural/20261113_pro_echo_construction/README.md)沿用原 P030 的 float32／tanh／兩通道 `Model.forward()`，同 UR1 的 L80/H64。手工一次設定 72 個非零參數，啟用八個 bit gate 加一個 STOP gate，其他 hidden 不作用。輸入只有八位元 Q 與模型自己的輸出 prefix；沒有 `|`、額外 cursor 或強制第九步停止。安全 cap 事先固定為 16。

固定 N=8 的知識寫在權重裡：以既有 padding occupancy 判斷已答幾位，再選 Q 的相應位元。對全部 256 個八位元 Q 各自由生成一次，**256/256 完整 Q+STOP 正確**。實際 2,304 次原 forward／24,035,328 dense MAC；optimizer 與 training MAC 為 0。完整人工 state、256 題逐步 logits、計畫與程式 hash 都保存。

這是有限固定長度裸位元 Echo 的表達能力反例，**不是學習成果、不是 UR1 成功、不是更長位數的泛化，也沒有給既有 UR1 學生安裝人工權重**。它與 P027 的「真的訓練成功」、PR13 的「通知已教近全會但未教搭配仍失敗」各回答一個不同問題。

外部 F：Zhang 等的 [Identity Crisis（ICLR 2020）](https://arxiv.org/abs/1902.04698)直接研究 identity 學習，顯示架構偏好會影響訓練後得到記憶式映射或 identity。這支持區分表示能力與訓練歸納的必要性；其影像／identity 設定不是本批二元自回歸通知，不能把文中 FCN 成績搬來診斷 UR1，也不由一篇論文宣判 dense 不適合本計畫。

## 5. 教材數字需保留原單位

F：[先前 P035 審核 JSON](../../experiments/spiral_neural/20261113_pro_p035_review/results.json)的 `courses_regenerated=30` 是 2 種 F/G 策略 × 3 seeds × 5 stages 的**階段課序**，不是 30 道訓練題，也不是 30 套完整五階課程。`actual_final_checkpoint_rows=64` 是 seed202 的四個 final 學生各評估 16 題，屬**審核推論次數**，不是 64 題訓練題庫。

P035 實際 F 每學生 15,000 次呈現／66,000 更新，G 每學生 17,973 次呈現／76,337 更新，12 學生共 197,838 次呈現／854,022 更新，另完整 replay。各階不同訓練組合是 2、4、6、6、12。可以討論教材覆蓋稀少，但不能拿後驗審核的 30／64 當訓練量，再據此作因果解釋。

## 6. 接棒判斷與下一個候選

[更新] 固定回音具備可表達、也有有限學習成功的證據；目前 UR1 的主要未過項是搭配泛化，且已教擬合仍有兩個錯誤。

[取代] 將所有失敗概括成「全連接很難回音」，或將 P029 到八位元等同物理擴網／零樣本升階成功。

[原因] P027／P029／P030 原始來源、PR13 同條件次序對照，以及本輪人工構造分別限定了能說的結論。

[狀態] 上述範圍判斷信心高；「教材更充分就一定能學會儀式」仍是信心中低的假說。確認通知回覆更不等於通知已促成新語義、物理擴網或降低後續學習成本。

A 候選：下一個正式學習問題宜縮成「在相同純 01 模型與 target 預算下，增加其他合法地址的跨寬度教材，是否改善既有六個未教搭配？」保持六個舊保留搭配不入訓練，新地址需在相同控制碼、深度與 context 範圍內合法，避免同時換網路、分隔符、算符或生成上限。這比較的是教材多樣性與重複曝光的**政策取捨**，因總預算固定，不能宣稱每題曝光也相同。

這只是下一棒的單一變因候選，尚無正式資料量或課序 manifest，也沒有新訓練啟動。Codex 接回後先核對既有合法地址與 prefix 標籤一致性，再凍結精確資料、固定 seed、預算與結果判準。六個舊保留搭配已看過，只能繼續稱曝光診斷；若要新盲測，需另外事前凍結未查看的題域，不拿舊六題反覆挑模型。不能把本候選當成「補資料一定有效」或漏報已完成的 P033 pair 覆蓋診斷。
