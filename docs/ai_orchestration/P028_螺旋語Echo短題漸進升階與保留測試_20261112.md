## P028 勘誤：升階是擴位，不是更換詞典 ID（U 2026-11-12）

使用者再次明確更正：「**不會重編，例如算子數字只是多一位數**。」先前文件把「保持原 ID、按當前 n 擴位」寫得像要重新分配舊詞碼/語義，是不精確的。**普通資料/數字詞的升階只是在資訊位的高位增加1 bit；舊數值、舊低位、舊詞義與既有編號保持不變**。例如 k=1、數值1：`10 → 010 → 0010`（只是左邊新增高位0），不是將數值1改配其他詞典 ID。新數值可以使用新增高位為1的空間。這不代表位元字串完全不變，長度當然增加。

此規則只描述**資料/算子數字分支增加一位資訊位**；不意味算符分支也必須一起升階或重新分配算符。已啟用的句號 `110→1110` 是依控制碼公式擴位的特例，不是任意重分配 ID；未啟用前不能當保留詞。歷史舊碼回放需要版本 context，但**不能因歷史文件所說「重編碼」就實作全詞典重映射**。做網路動態擴容對照時請固定舊輸入位/隱藏神經元的權重與 Adam 狀態，新增位置/神經元採新初始化；要明確記錄資料詞如何對齊，避免高位插入導致舊位置被無意挪動。全句前綴長度變動仍須另做位置回歸檢查。

## 1. 本輪固定的「原始論文一層 Echo 子集」

**先教「資料詞升階」（n_data 增加），不是一開始就同時教升層（k 增加）。**

- 在最初例題：`01` 是啟用 **k=1** 一層語場；`00` 是此教學 profile 的 Echo 算符。故常見原始前綴 `0100` 實際為 `01|00`，**不要把 `0100` 當單一 Echo 算符**。其他 profile 的 `0100` 可能是 neg、zero、批改等，必須保留版本/上下文。
- 令資料詞 `D(n,v) = binary(v, width=n) + "0"`，`0 <= v < 2^n`，這個詞的物理長度為 `n+1` bits、末尾有一個**語法尾 0**。該尾零是答案的一部分，禁止任意剝除。
- 本階段題目 `Q = "01" + "00" + D(n,v)`，答案 `A = D(n,v)`；模型逐 bit 輸出 A，最後**額外**輸出 `STOP`。
- `|`（在人類展示 `01|00|D`）只為展示詞界；模型輸入中的 `｜` 是**題目與已答內容的外部訓練分隔符**，不是螺旋語的句號／詞尾，也不算在 raw 題目 bits 裡。
- `STOP` 是此次自回歸環境的外部結束動作，**不是螺旋語的一層句號 `10/110/1110`**。不要混同。
- 本輪題庫不是「完整任意螺旋語」而是**原論文 Q1–Q3 的有範圍 Echo 教材**。`01|00|010` 使用原來的 Echo 算符 `00` 與較長的資料詞 `010`；不能誤以為本次同時把算符擴階。

### 必須通過的樣例

| 題目分段（僅人工展示） | raw 題目 | 正解（不含外部 STOP） | 意義 |
|---|---|---|---|
| `01|00|00` | `010000` | `00` | n_data=1, v=0 |
| `01|00|10` | `010010` | `10` | n_data=1, v=1 |
| `01|00|010` | `0100010` | `010` | n_data=2, v=1，出自原稿 Q3 |
| `01|00|100` | `0100100` | `100` | n_data=2, v=2 |
| `01|00|1010` | `01001010` | `1010` | n_data=3, v=5 |

每題的 supervised pair 必須正確：`Q｜`→首個答案 bit、`Q｜a_1…a_i`→下一 bit、`Q｜A`→STOP。不得餵入未來正解 bit。

### n 與詞數，禁止犯的錯誤

`n=1` => 資料詞 2 bits、合法詞 2 個（00、10）；  
`n=2` => 資料詞 3 bits、合法詞 4 個（000、010、100、110）；  
`n=3` => 資料詞 4 bits、合法詞 8 個（0000…1110，全部以 0 結尾）；  
…依次至 `n=8` => 資料詞 9 bits、合法詞 256 個，對應 P027 舊長度作回歸。  
在固定 k=1 的本段，只增加**資料詞** n，不宣稱所有算符分支也同步升階。原論文更完整的擴階及詞表／版本切換是後續獨立測項。**升階不退回**：例如資料詞原 n=1 的 `10`（資訊值1）升到 n=2 應用 `010`、升到 n=3 應用 `0010`；原 n=1 的 `00` 升到 n=2 是 `000`。正式教學／推理都用**當前 n** 編碼；不能將前階原 raw 字串混進當前 profile 冒充舊題保留。原歷史封包若要重播，必須帶**明確舊版本 context** 交給解析器，**不表示學生倒退學舊階**。

## 3. 三條研究線（先短後長，不把方法混成一組）

### P028A：逐階課程（主研究）

依序 `n_data = 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8`，**對每隻學生只升不退**。沿用**同一組模型權重**進階，不在升階時重新隨機初始化；記錄 Adam optimizer 狀態是否保留（主研究固定保留），如果想重置須另列對照。`current_n` 只可增加，不可下降；題庫與出題器在升階事件後一律改用新階詞碼。若想複習舊概念，**維持原值並擴到 current_n 資訊位寬**，不可把舊原始詞碼原樣插回模型訓練或測試。

事前固定各階最大曝光上限建議：`[500,500,750,1000,1500,2000,3000,5000]`，上限不是必須跑滿，達成功門檻即可升階；若到上限還沒達標，標記失敗並停下該 seed，不能卡在同一題無限重試。嚴禁臨時提高上限後選最好結果當主要結果。Codex 可基於 CPU 預算在實跑前一次性修訂上限、並寫入 plan；啟動後固定。

通過門檻：小階 `n=1..4` 需**所有合法資料詞**在自由生成下完整正確且 STOP 位置正確，連續三個檢查點達標；`n>=5` 需事先固定的**驗證集**至少 95% 全串正確、STOP 至少 95%，連續三個檢查點達標。每次升階均測**舊概念在新階的正確率**（值、語義保留，以 current_n 高位補0擴位（原低位不變）），不要退回舊 n 測舊 raw 句；若舊概念失敗立刻記錄語義遺忘，而不是混入不同階數的舊題。**若想以「三次」判穩定，必須三次之間真的發生新訓練，不能同一權重原地測三次。**

低階有限全集可做全題正確測試，但因為訓練可能已見過，**不得叫做未見題泛化**。n>=5 的資料事前分為訓練、驗證、最終測試，固定分割且不洩漏最終測試答案；驗證只用於升階，最終測試不拿來調整課程。建議 n=5..8 用 75% train/12.5% val/12.5% final test（n=5為24/4/4；n=8為192/32/32），每階拆分需由確定性 PRNG 重現。所有資料都是真正合法的螺旋資料詞。

每階記錄達到 50%、90%、95%、100%（如可能）的**最早曝光題次**；不以最終 5000/20000 題成績代替學習所需題數。**專門檢查使用者預測「100題左右學會」**：每階在 0、1、2、4、8、16、25、50、75、100、128、192、256、384、512、768、1000、2000、5000（受上限裁切）等預先固定題次記錄曲線，並記錄升階後第100題的成績。測試本身不得更新權重。

### P028B：8-bit / n=8 從零直學（必備對照）

同一 MLP、相同訓練資料切分、相同 seeds、相同更新策略：直接從 `n_data=8` 起學。對照 P028A **第一次抵達 n=8** 和同樣累積 `optimizer updates` / `target token 曝光` / walltime / n=8 教材曝光數時的表現；繪製匹配預算曲線。不可以用「A用了很多短題」去跟「B只看一點長題」就聲稱升階有效，也不可因 B 比 A 晚達標就忽略 A 的前面成本。

### P028C：當階舊概念複習（重要對照）

仍採**單調 n=1→8，不退階**。在每次升階至 n_new 後，讓一組學生只練新階任意詞，另一組學生按固定比例加入**從先前 n_old 的值/概念集合取樣、以 n_new 重編碼**的複習題；同一模型不接受舊 raw 詞碼。預先指定複習比例（初步 20%，也可於事前 plan 調整），記錄舊概念保留率、新概念泛化率、每階總成本。與 A 必須使用相同種子、相同總預算，以辨別複習是否有幫助。若要做同時混合 `n=1..8` 的對照，只能另開**明確帶版本的多 profile 模式**，不能偷稱為本次只升不退的螺旋語課程。

每組至少 3 個 seeds；如資源允許增加至5個，但三組/所有seed必須完整報告，不要只挑成功 seed。若 runtime 不足，先跑 A+B，明確把 C 列待做，不能聲稱已比較。

## 4. P028D：算符本身的升階（與資料長度分開，主線完成才做）

原始論文一層算符示例：n_op=1 `Echo=00`；n_op=2 `Echo=000`、`NegEcho=010`、`Zero=100`、`END=110`，並可隨後 n_op 增加。這是詞表/算符分支的升階，**不能把 `01|00|010` 誤稱算符升階**。先單獨測 `01|000|D` 的 Echo，明確指定算符寬度 profile，並和既有 `01|00|D` 版本隔離；必要時加**有定義的版本／語境訊號**，不能讓同一裸位元流在兩個 profile 下無共識猜切詞。
- 先檢驗 Echo 由舊詞碼轉到當前新詞碼是否能遷移、舊概念是否仍會；歷史舊封包另用明確 version/profile 的獨立回放測試，不令新版本學生退回舊算符碼。再加入 `NegEcho`，其定義是**翻轉資料資訊位、保留詞尾0**，而非連尾零一起翻轉。
- 原論文例：`01|010|100` → `010`（NegEcho）。對照 `01|000|100` → `100`（n_op=2 Echo）。注意兩者的完整詞界和版本。
- 不要在加入 NegEcho 的同一輪又改資料階、句號、回饋和網路大小。測相同資料下不同算符答案可區分，反例避免學生只複製最後資料詞。

## 5A. P028F｜固定詞長先學、切詞符號支援自由詞長（另立對照）

**使用者新增研究方向（U，2026-11-12）**：額外切詞符號可能讓同一句混用長短詞，但前期固定詞長可能比較好學。**二者都是待驗假說；不得直接聲稱 WB 效率更高或固定詞長一定更容易。**先完成 P028A 的只升不退升階線，再另開切詞實驗，不在 P028A 中途改輸出詞表。

### F0：初期固定詞長（既有主線）
- 模型**輸入**三類：`0`、`1`、題答分隔 `｜`；**輸出**三類：`0`、`1`、`STOP`。題答分隔不等於 STOP，也不是螺旋語內在的句號。
- 遵照原始螺旋語 profile 的 `k/n/offset` 及尾碼 `0^k`。當前分支 `n` 升階後不退回；舊概念在新階高位補0擴位（舊低位與詞義不變），不得重新拿歷史裸碼當目前的訓練題。
- 從 n=1 的最短題開始，依 P028A 記錄每階首次達標題數與概念遷移；不再以 8-bit 為無條件初始長度。

### F1：多詞可變長的新方案（明確分為兩種語法）
- WB 是獨立「詞界」token，不是尾碼0、題答分隔或 STOP。例如人類展示 `00 WB 1010 WB 110 WB 00010 WB`。加 WB 能表達詞界，但**不能自動定義該詞意思、詞的層級或版本**。
- **F1a 冗餘邊界**：仍然保留螺旋語詞身及尾 `0^k`，且各分支依當前 profile 知道 n；WB 額外指示詞界，檢查是否更容易學。這是原生語法上疊加教學輔助標記，可能增加傳輸成本。
- **F1b WB 主導的可變長詞**：允許依 WB 直接定界，各詞不必固定同一 n。必須先規範空詞、非法 WB、同一概念的多種長度編碼、作用域、層級、詞典與版本。**這是新的編碼 profile，不能說只多一符號就等同原版螺旋語。**
- 在 F1b 裡「自由長短」不等於「退回舊階」；同一當前 profile 可讓不同詞有不同長度，但版本/詞典演化方向仍需單調，不能把歷史編碼當成現行編碼而不作標示。

### F2：符號位置與網路大小的對照
- **教師只在輸入放 WB**，學生仍輸出 0/1/STOP：若固定23輸入位置、16隱藏神經元，input 由3→4 channels，output 仍3 classes，參數由1171→**1539**：`(23×4+1)×16 + (16+1)×3 = 1539`。這是教師額外提供詞界的實驗，**不是學生學會輸出切詞**。
- **學生也要輸出 WB**，模型在生成多詞答案時可自主產出 WB：input 4 channels、output 4 classes（0/1/WB/STOP）；同上述固定23位置時參數 **1556**：`(23×4+1)×16 + (16+1)×4 = 1556`。每個詞界都要花額外輸出步數，23槽可能不夠，必須預先算最大輸入長度、拒絕靜默截斷。
- 若擴大位置或參數，原無 WB 對照也要有相近容量與運算預算組；不可把增加的輸入資訊、模型容量、輸出長度改變統統歸因於 WB。教師補詞界的 F2-提示組、學生自主切詞組不得混為同一實驗。

### F3：先固定再轉自由，與一開始自由的成本比較
- 固定詞長學習成功後，複製同一 checkpoint，規範新增 WB 的輸入/輸出權重初始化，做「先固定→再自由」的轉換；另設「從零開始直接教 WB 自由詞長」與「持續固定詞長」對照。
- 第一個真正能看出 WB 價值的題型應是**多詞、長短混雜，且需要真正找詞界才能正確生成/判讀**；單一 Echo 資料詞後面直接 STOP，額外 WB 很可能沒有好處。
- 評估第25/50/100題、每階升級後所需題次；分開統計自由生成正確率、詞界定位 F1/precision/recall、STOP、舊概念保留率，以及**總輸入輸出 token、raw bit/控制開銷、實際參數、更新數、FLOPs、walltime、RAM**。只有各組任務相同、總成本可比才能稱有效率優勢。

**順序**：F0 立即實驗；F1–F3 先完成可執行語法/成本規格，後續另立受控實跑。不必因為 WB 值得研究，就立即改掉已經成功的三輸出小模型。

## 6. 測量、反例、驗收

每一階/每個 seed（訓練與最終測試分開）記錄：累積題次、各階題次與 unique 題、當前梯度更新/已訓練 token 數、CE loss、teacher-forced 下一詞準確率、greedy 自由生成全串準確率、逐 bit 位置準確率、STOP 時機、舊階遺忘、訓練耗時及推理次數、當前 profile `k/n_op/n_data`。**首次通過點**和**連續通過點**分開。

必測：
1. 詞碼 oracle `parse(encode(...))` 一致，原論文 Q1/Q2/Q3、NegEcho 例題逐字核對；版本隔離，未知 profile 拒絕而不是猜。
2. n=1..8 的每個合法資料詞都以 `0` 結尾，詞總數 `2^n`，答案長度 `n+1`，STOP 恰在其後；題目 raw 長度 `n+5`，input 最大長度 `2n+7<=23`。
3. 訓練有完整輪替，答錯仍換下一題；各階 train/validation/test 不互相污染，模型輸入不含正解未來部分。
4. teacher forcing 訓練，free-run 評估，兩者報表分開；測試不更新權重，停止與尾零不是同一符號。
5. n=8 舊固定長度基準保留可重跑；不得拿 P027 的既有64保留題冒稱未看過的全新 blind set。
6. 實際升階後舊概念回歸：用**當前階擴位**舊資訊值，測會不會遺忘；不以舊 n 裸碼重新出題，不能只記錄新階分數。並加 assert `current_n_next >= current_n_previous`，除非是完全獨立、從零新建的對照模型。
7. 同 seed 的重播與梯度檢查；記下每個檔案 SHA/commit、程式改動清單、所有 pass/fail。

## 7. 成功條件與允許 Codex 的自主空間

主成功不是「最後 n=8 分數100%」；它是**只升不退的學習曲線 + 新階的學習成本 + 舊概念以新階擴位後的保留率**。即使升階沒成功，只要證據能辨別是資料太少、位置對齊、模型容量、STOP、訓練目標或忘記舊階，也值得保留。

Codex 可自主完成 oracle、資料生成、紀錄、決定性測試與畫圖；不得自行把用戶的「升階」換成「增加隨機輸入字串」、把 `k` 與 `n` 混同、加入外部 n 提示、換大模型、換詞表或硬編答案。若單一參數/資料分割與 P027 實作衝突，先在事前 plan 註明，固定後再訓練；重大的設計衝突須回報，不得默默改變。

執行順序：**audit → oracle+樣例測試 → P028A 單調升階曲線 → P028B/C 對照 → P028D 獨立算符升階（有時間才做） → P028E 規格草案 → P028F 切詞標記成本與可能實驗**。保留 P025–P027 全部歷史。交付獨立 `P028` 程式、完整逐題指標 CSV/JSON、參數 checkpoint、圖表和一份中文報告，回報最早達標題次及下個可驗證問題。
