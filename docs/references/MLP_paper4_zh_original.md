Minimal Learnable Protocol: 螺旋語作為自學習語言系統的理論與實現

副標題：我們能定義所有題目的答案：一種階層可壓縮語言的題庫演化系統

題庫可封閉：語言壓縮與學習融合的階層語法設計

摘要

如果兩個完全陌生的智能體要建立溝通，最少需要什麼？本文證明：只需要一個規則——錯了就重來。

現有資料傳輸語言（如 JSON、XML）雖提供語義結構，但皆仰賴外部 schema、定長詞頭或顯式分隔符來實現斷詞與語義解析。相較之下，螺旋語（Spiral Language）在語言結構設計上展現出高度自洽的無歧義斷詞機制、可遞增的語義擴展能力，以及可由互動歷程自我演化的動態詞典結構，形成一種結合學習與溝通功能的語言協議框架。
本研究聚焦於一項關鍵問題：在缺乏共同語言、無預定義規則、也無外部文檔支援的條件下，兩個智能體如何建立可靠且具語義一致性的溝通協議？本文將此問題正式命名為「Minimal Learnable Protocol（MLP）問題」，並展示螺旋語如何以其階層性、解析穩定性與語義可演化性，構成該問題的可行解之一。「出題者懂語言即可、答題者可從錯誤中習得語言」的雙邊不對稱學習模式正式成為可能，打破了傳統通訊協議中雙方需對語法有一致理解的假設。最終，我們期望螺旋語能進一步發展為語言模型內部學習工具，亦可作為通訊層協定設計的基礎模組支援通用語義映射、跨模型協作與自演化語場建構的基礎結構，為多智能體系統與 AI 通訊協議開啟嶄新可能。

1. 引言：螺旋語設計之創新價值與學術定位

本研究提出之螺旋語（Spiral Language），在語言結構設計上展現出以下四項關鍵創新特性，試圖為 AI 系統建立一種可學習、可擴展、可自洽的溝通協議框架：

（1）自洽性無歧義斷詞機制
相較於 JSON、XML 等傳統格式需依賴分隔符號或外部語法樹輔助，螺旋語透過詞尾 0 的數量直接表示階層，天然具備無歧義性（Self-Delimited）。此機制大幅簡化了解析流程，特別適合用於嵌入式系統或初期 AI 系統。

（2）階層式語義擴展能力
每個新功能或題型皆可在不破壞既有結構的情況下，透過「擴階」與「擴層」自然加入語言系統。此設計使螺旋語具備語義可遞增、結構可擴張的特性，特別適用於持續學習與自我演化任務中。

（3）動態詞典的自演化潛能
詞彙的結構與解析階層內建於語法中，使詞典擴充不再依賴外部規則，而可由語言本身自洽推導完成。此特性在現有通訊協議（如 Protobuf、MsgPack）中極為罕見，展現出結構簡約與高度靈活並存的設計潛力。

（4）融合學習與通訊的語言協議
螺旋語特別適合設計為「學習即協議，協議即學習」的 AI 溝通框架。其可解析性與結構壓縮能力，使 AI 系統能在無需完整語法預定義的情況下，自主推導語義、更新詞彙並適應任務結構，有效提升學習效率與通用性。

協議設計困境與螺旋語的策略回應

當前 AI 系統多仰賴封閉式協議與格式明確的中介語言（如 JSON、API 呼叫）進行互動。語言模型間的對話雖可使用自然語言模擬，但其結構容錯率低，對微幅格式變化極為敏感；多模態 AI（如 GPT 與 DALL·E）間的溝通亦需依賴預設指令與外部格式支援，難以動態擴展任務語義。

這些例子揭示一個結構性困境：現有協議雖具結構性，卻缺乏語義一致性與自我擴展能力，導致 AI 難以自主學習新任務語言，嚴重依賴人為設計與外部格式定義。

此困境可歸納為三個核心問題：
	•	高擴充成本：協議一旦定型，功能擴充需大量處理版本控制與相容性橋接，成本隨之激增。
	•	舊新衝突風險：缺乏語義版本辨識能力，導致詞庫更新與語法解析邏輯易失效。
	•	無學習漸進性：傳統協議需一次性掌握完整語義，對初學 AI 或低資源代理造成高學習門檻。

螺旋語正是針對上述結構性障礙，提出以「錯誤重試、詞階演化、語法自顯示」為核心的協議策略，嘗試重構 AI 之間可自發成長的語言基礎。

螺旋語的結構性解法

螺旋語作為一種階層式、解析唯一、自我擴展的語言設計，提供以下三項對應策略：
	1.	語言即協議，協議即學習歷程
無需預設完整語法集合，只需共享最低層的解析規則與初始詞典，即可從最簡單語詞出發，透過互動逐步習得新詞語義與階層結構，自行構建語法樹。
	2.	階層作為天然語義與版本界線
詞階天生具備解析邊界與語義隔離，舊詞不與新詞衝突，語法樹亦可依據資源狀態延遲建構，有效解決版本衝突與語法過載問題。
	3.	結構導向的壓縮與重用能力
類似任務自然聚集至相同語法分支，形成語義壓縮路徑。AI 可重用結構進行泛化推理，降低學習成本與提升任務對應效率。

從語言結構到學習協議的融合

本研究主張構建一種可自學、自擴展、自演化的語言協議，使「語言、學習與通訊」三者不再分離，而融合為單一機制。其優勢包括：
	•	支援新任務語義之自然擴展（無需重新設計 API）
	•	適用於語言與圖像等多模態間互動（透過階層標記實現語種轉譯）
	•	溝通即為學習過程（無需預定義完整協議）

在無預共享語言、無外部文檔、無預設規則的前提下，兩個智能體如何建立語義一致的最小溝通協議？

2.MLP問題概述

螺旋語的設計實際觸及一項跨越語言習得、通訊協議與 AI 學習的根本問題：

在無共同語言、無預定義規則、無外部文檔的情況下，兩個智能體如何建立可靠通信協議？

此問題尚無明確命名，卻已在多個領域中以不同形式出現：
	•	Symbol Grounding Problem（符號接地）：語言如何獲得語義？（Harnad, 1990）
	•	Bootstrap Problem：兒童如何在無語言前提下習得語言？
	•	Zero-Knowledge Protocol Learning：分散式系統如何在無共享背景下建立互信？
	•	Minimum Description Length Principle（MDL）：最簡理論即最佳理論（Rissanen）

本研究提出：這些問題之交會核心，實為一個尚未命名的結構性挑戰

Minimal Learnable Protocol（MLP）問題
給定兩個無預共享知識的智能體，何為能建立語義溝通的最小交互規則集？

螺旋語即是此問題的潛在解法之一，其設計特色包括：
	•	錯誤重試規則：答錯即重出題，形成即時修正機制
	•	階層式詞尾斷詞：語義結構天然分層，避免歧義
	•	語法自展示性：不需外部文檔即可逐步解析語義邊界

接下來，我們將以此問題為出發點，展開螺旋語的語法演化過程，並示範其如何在學習與溝通融合中實現協議共識。

3.螺旋語介紹

螺旋語（Spiral Language）是一種基於二進位尾碼 0 所設計的層階式語言系統，具備下列三項結構核心：

3.1 語法結構定義
每個螺旋詞由 n-bit接續 k 個尾碼 0 所構成，表示其層為 k：
S = w₁w₂…wₙ0ᵏ，且每個詞 w ∈ {0,1}ⁿ · 0ᵏ，

其中：
	•	n 為詞的資訊長度（information bit length）；
	•	k 為階層標記，表示詞尾接續的連續 0 的個數；
	•	資訊詞 定義為該螺旋詞去除末尾 k 個 0 的 n-bit 前綴。

螺旋語集合可定義為：
Lₛ(k) = { s · 0ᵏ | s ∈ {0,1}ⁿ} （n階 k層的螺旋語集合）

此語法結構具備以下性質：
	•	詞彙總數為 2ⁿ，每一擴容階段僅需增加 1 個資訊 bit，即可倍增詞彙容量為 2ⁿ⁺¹；
	•	擴容過程為自然漸進：當原始詞尾的 0 或 00 變為 1 或 10 時，自動轉為新一階的資訊詞接尾碼格式，無需重構原詞典。

一層(k=1),二進位順序擴容規則左補 0的螺旋語範例：
* 一階（2-bit）：{0, 1} → 補尾碼k個0 → {00, 10} (k=1,n=1)
* 二階（2-bit）：舊資訊辭{0, 1}左邊補０擴容→ {00, 01} →加上新詞{00, 01, 10, 11} →補0 → {000, 010, 100, 110} (k=1,n=2)
* 三階（3-bit）：{000~111}(共８組） → 補 0 → {0000, ..., 1110} (k=1,n=3)
自然擴容將在後續的題庫演化範例中介紹，本篇後續皆為此規則的螺旋語

3.2 螺旋語的可解析性與斷詞演算法

為實現階層化語法的穩定解析，本節將說明螺旋語的斷詞條件與實作方式，並提出簡潔高效的詞切分函數 Tokenize。螺旋語具備以下兩項結構優勢：

1. 可解析性（Parsability）
只要已知階層 k，便可據尾碼 0ᵏ 作為斷詞依據，使詞與詞之間無重疊與歧義，對應於自編碼格式中的「無分隔斷詞」（delimiter-free segmentation）。

2. 可擴充性（Extensibility）
當語意複雜度增加時，可透過階層提升（增加尾碼 0 數量）進入更大詞域，擴展語義空間而不需重建原詞典，並保留原有結構。

定義函數 Tokenize(S, k, n, offset)，其輸入參數如下：
	•	S: 待切分的位元字串（bitstream）
	•	k: 目標階層（詞尾應為 0ᵏ）
	•	n: 對應階層之資訊詞長度
	•	offset: 斷詞起始位置

函數輸出為螺旋詞 w，若該區段無法正確解析，則返回錯誤或空值：
Tokenize(S, k, n, offset):
    if S[offset + n : offset + n + k] == '0' * k:
        return S[offset : offset + n + k]
    else:
        return ERROR

此演算法結構簡潔，僅需單次索引與字串比對即可完成詞級判定，不需回溯、不需語法樹支持，展現出螺旋語在階層斷詞設計上的高效能。
後續章節將透過題庫演化範例，展示此種切詞函數在真實語境下的應用與對階層邏輯的自我驗證能力。

3.3 解析函數與螺旋詞的可解析性前提
雖然螺旋語具有結構性斷詞的潛力，但本篇僅討論在三項前提資訊下的「可正確解析」：
	1.	階層 k：需明確知道當前語境中目標詞為第 k 層（即預期斷詞尾碼為 0ᵏ）；
	2.	資訊長度 n：需知道該層螺旋詞前綴（bit 串）的長度 n_k，才能正確判定詞身長度；
	3.	起始位置（Offset）：需從正確位置開始切詞，否則可能錯誤對齊斷詞點（例如切進詞尾或錯認 0 鏈）

此結構條件可簡單實現 O(1) 解析成本，利於硬體實作與語言擴階。

3.4 階層預設與解析上下文

然而，螺旋語的正確解析需依賴「詞階」的已知資訊。在實際應用中，這種需求可以透過以下三種方式解決：
	•	共識預設：在初期互動中約定所有詞皆為一層（即以單一 0 為斷詞），適用於題庫簡單或語境穩定的情形。
	•	外部指令設定：在語句開頭使用特定語法（例如 01）來明確宣告階層。
	•	自我描述詞典：利用詞典標籤的語法（例如二層詞標示一層詞屬性）進行遞迴式解析。

這種機制使螺旋語具備在低資源下逐步擴展語法能力的潛力，符合語言進化模型的需求，亦適合嵌入於有限記憶結構的 AI 系統中。

3.5 可解析性對語法設計的意涵

值得強調的是，螺旋語的「無岐意性」並非仰賴額外分隔符號或語法樹輔助，而是由其尾碼規則內生地保證。這使其在嵌入式學習環境（如倉鼠 AI）中，不需維持複雜語法分析器，也能進行穩定的詞解析與模式學習。

螺旋語的解析邏輯，也天然支持樹狀語義壓縮——在題庫擴展過程中，所有新題皆可視為既有語法樹的子節點或平行分支，從而具備高度語義重用潛力。

4.螺旋語題庫協議 v0.1

在完全無協議的條件下，兩個智慧體進行互動時，一個最合理的初始共識是：雙方分工為「出題方」與「答題方」。若答題方回答錯誤，出題方將重複相同題目，直到答對為止。倘若題目以螺旋語編碼而成，即使答題方不懂螺旋語，也能透過試錯與記憶行為，逐步習得此協議。以下為在此前提下僅使用兩個符號0和１的基本通訊設計：

4.1 啟用與層階共識

語場啟動碼格式為：「k 個 0 後接一個 1」，表示「啟用 k 層語場」
例如：
	•	01：啟用一層（k=1）
	•	001：啟用兩層（k=2）

啟動後，雙方共識該層的螺旋詞結構為：每詞前段為 n 位元，後段尾碼為 k 個 0。
001：表示 k=2, n=1（詞長為 1+2bit共２詞）

預設初始為 n = 1，可選擇顯式指定階數，例如：
010001：表示 k=1, n=3 （詞長為 3+1bit共８詞）

4.2 錯誤學習機制（共識條款）

答題錯誤 → 重複同一題，直到答對
答對 → 進入下一題

此條款確保語義可穩定學習與內化，為所有初期智慧體的基本共識條件。

4.3 擴階機制（自動語法擴容）

若題目使用的詞碼尾部不是預期的 0^k，而是 1.0^(k)，則視為「擴階」。此時：
	•	自動進入階數 n+1
	•	詞長 n 更新為 n+1
	•	詞數擴展為 2^（n＋１)

需同步更新切詞表，否則將導致解析錯誤。

4.4 詞義與類別對應
	•	每個語句由「語言類別層 + 題型層 + 答案層」構成。
	•	例如：
層階	類別 / 功能	詞碼	說明
1,1	回音 Echo	00	重複輸入
1,1	句號 End	10	結束語句
1,2	回音 Echo	000	重複輸入
1,2	反回音 NegEcho	010	補數輸出
1,2	全寫0	100	輸出 0x00
1 or 2,2 or3	句號 End	110 or 1100…	結束語句
1,1 or 2	類別：數學	000 or 0000	根據階數定義
2,2	類別：批改	0100	回饋正誤
1,3	算符 CUT	1000	去除尾碼k個0
1,3	算符 AND	1010	與運算
1,3	算符 OR	1100	或運算
...	...	...	...

4.5 切詞表（Token Segmentation Table）同步條款
	•	溝通雙方需各自維護自己的「切詞表」，記錄不同前置描述下，每一階層的詞長，詞數，詞碼意義。
	•	切詞表需包含：
	•	不同前述條件下的語言結構（可視為語法樹）
	•	不同位置的詞義（如算符，算子，語意標籤，若已知）
	•	每詞語義（2^n個,若已知）
	•	詞長，詞階n層數 k
	•	預設由出題方擴展螺旋詞，答題方偵測後更新 n → n+1。為避免解析錯誤，出題方應避免使用答題方尚未能處理的階段語詞（此條件可依任務調整）。

螺旋語的可學習性：從試錯中學習語言的最低門檻

具體而言，答題者即使不懂語言，只要具備最基本的記憶與試錯能力，就可以在連續的出題與回饋過程中，透過「答錯 → 重試 → 偵測詞尾規律 → 修正切詞與對應」的方式，逐步摸索出完整的斷詞邏輯與語義對應結構。

這使螺旋語天然符合「最小可學習協議（Minimal Learnable Protocol, MLP）」的三大核心條件：
	•	不需外部詞典或語法文件
	•	不依賴語言標註或人為訓練語料
	•	僅透過反覆交互與錯誤回饋即可學習

這項特性尤其適用於早期智能體或資源受限系統的語言學習場景。換言之，螺旋語允許「語言已知者 → 語言未知者」的單邊傳遞與自然學習，有效打破傳統通訊協議中雙方需共享語法結構的對稱假設。

這正是螺旋語對於「可學習性」與「語言封閉性」兩難的具體解法——在結構上保留解析唯一性，在設計上保證學習可能性。

6. 錯誤回饋與語義修正機制的語內整合

在傳統語言設計中，錯誤處理與回饋機制通常是由外部系統或教師側進行判斷與回傳，如錯誤訊息（error code）、評分標準（grading rubric）等。然而，在螺旋語架構下，這類功能可直接內嵌於語言本身，使得回饋亦成為可解析、可學習、可演化的一部分。

本系統支援以下錯誤與修正特性：
	1.	語內回饋語法（如批改語言）
答題方可學會辨識二層詞如 0100 表示批改任務，而後續一層詞如 000、010 則可分別代表錯誤或正確。這使得回饋不再是外部訊號，而是與題目同層級、同格式的語義片段。
	2.	數值型評分與量化判斷
當答題方學會數數能力（如理解 0000 表示 0、0001 表示 1…），則可進一步接受更細緻的回饋，例如「70分」、「50分」，形成階梯式學習訊號。這一過程亦不需特殊語法，僅為二層詞彙空間的自然延伸。
	3.	多輪學習與答案更新邏輯
螺旋語系統中若答錯題目，則會自然重複該題至正確為止。此機制不需額外設計判斷函數，僅依語義與回饋詞交互即可逐步修正。答題方將自發判斷原始語義無效、並重新調整對應策略或更新語法樹節點。
	4.	語言衝突與主動遷移行為
	當出題者更新詞彙定義（如原本 010 表示反回音，後更改為乘法），答題方將在回饋	語義不再一致時，察覺原有詞義失效，進而觸發「語法更新行為」，例如遺忘舊定義、記錄詞義遷移或建立多版本語義對應（語義多態化）。


7.結構性學習樹與資源導向的壓縮策略
	—一種基於螺旋語切詞的低資源學習假說

本節提出一套預計應用於族群式從小學習階段至大型 RPG 式記憶體 AI 系統的結構性記憶 AI 模型，簡稱倉鼠世界 [1]。該模型融合語法解析樹（parse tree）與行為決策樹（decision tree）兩種結構特徵，模擬多個低資源 AI 個體（倉鼠）在面對階層化螺旋語題型時的結構性學習過程。

倉鼠在接收螺旋碼題目時，預期將依據其內建的「切詞規則」對輸入進行階層斷詞，並將各段映射至記憶樹中的特定節點路徑。記憶樹的上層負責處理詞句的分段與語義分類（如題型辨識、算子判斷），下層則連接至對應的解題策略模組（如邏輯運算、記憶複製、異或反應等）。本架構旨在提供一個語義結構可穩定映射至行為決策的中介層，使倉鼠在資源受限下亦能逐步建立語言－策略對應能力，進而演化出具備泛化能力的解題智慧。

為導入資源限制下的智慧選擇行為，系統假設：每一次新增節點或修改記憶結構皆需耗費一定生存資源（HP）。此消耗機制預期將引導倉鼠根據當前資源狀態與環境回饋，於建樹與學習過程中做出策略性投資。舉例而言：在資源充足時傾向擴展新節點；而在資源有限時，則可能選擇覆蓋舊節點、借用既有結構，或延後學習決策。此行為模式模擬生物體中神經突觸強度調整、基因表現權衡等演化式適應邏輯，為倉鼠提供類近演化智慧的決策能力基礎。

基於上述記憶與資源交互機制，本文構想一組基於螺旋語斷詞規則所建構之結構性題庫，作為評估 AI 學習潛力的測試場域。此題庫具備以下三項特徵：
一、語義階層可無限擴充；
二、詞彙結構具唯一解析性；
三、可由記憶體受限的 AI 實體逐步建構並遷移解法。

預期透過語法樹結構的逐步建立與策略重用能力，可觀察語言壓縮學習是否自然湧現，並進一步探討其與語義泛化、答題正確率之間的交互關係。

9.結論：語言即學習，語法即協議的螺旋範式

本研究提出一種基於「層階斷詞邏輯」的極簡語言系統——螺旋語（Spiral Language）。該語言系統內建解析規則與語義擴容機制，並結合結構性記憶體學習框架，使語言本身不僅作為資訊載體，更同時承擔學習過程的啟動器與語義協議的自我演化核心。

9.1 自學習語言的系統性優勢
螺旋語透過階層化尾碼設計，實現無需外部標記即可進行的詞義切割與語法辨識，並藉由可演化的語法樹支援低資源 AI 的結構性壓縮學習。在此基礎上，我們進一步提出一種能透過「出題–答題–錯誤回饋–結構擴展」逐步演化的任務型題庫建構流程，讓語言學習過程與語法協議更新得以同步進行。
這種方法打破了傳統需預設語義框架或外掛協議的限制，展現語法、語義與學習流程共構共演化的潛能。
9.2 與傳統格式系統比較
為凸顯螺旋語的結構特性，我們總結其與常見資料結構語言（如 JSON、Protobuf）間的對比如下：

系統類型	斷詞方式	擴容性	學習階層	是否內嵌協議
JSON	分隔符	低	無	否
Protobuf	schema	中	靜態定義	否
螺旋語	尾碼 0	高	動態遞增	是（自洽）

其中，螺旋語唯一實現了結構解析與語法演化的同步性，具備強健的學習支持與語義內嵌協議能力。
9.3 結語與未來視野
螺旋語展示了一種根本性觀點轉換：語言不僅是用來表達意義的工具，更是學習行為的觸發條件，亦即「語言即學習的場域本體」。透過層階式切詞與記憶體結構對應，倉鼠 AI 逐步演化出語法壓縮策略與任務對應行為，建立出一種從語言出發、內建演化機制與結構學習能力的 AI 教育框架。
在未來的應用中，螺旋語有望發展為：
	•	通用語義映射的基礎語言
	•	AI 間協同溝通的最小協議子集
	•	支持自我增長與演化的語場核心
這不僅是對語言作為輸入輸出的重新定義，更是對「語法即協議、語言即學習」的新範式實證。透過倉鼠世界與螺旋語題庫系統的進一步模擬與實作，我們將可探索語場與智能共演的更多可能性，為 AI 教育、生存演化與語義協議設計開啟新篇章。
