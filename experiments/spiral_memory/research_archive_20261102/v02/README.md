## 2026-11-02｜作者再次修正：AI 先當解析器（目前優先規則）

U 新指令：「你先自己當解析器就行了，程式只能先輔助。」這是對本原型**解析職責**的變更，不是要求另建一套硬式 parser。**以下舊章節把 Python 寫成「解析器／文法本體」的部分，均作歷史的機器輔助試驗，不得當成自然語言螺旋記憶的首要讀法。**

### AI 對作者當輪示例的直接讀法（A 解釋，非 U 定案語法）

原文：`領域，螺旋語實作到自然語言，原則，句號。不只是，螺旋語版本，加標籤，底層螺旋語化`

AI 直接理解為：建立討論領域「螺旋語如何實作到自然語言」，以「原則」標明論述性質；`句號` 是這個宣告的邊界。下一段的 `不只是` 建立「僅給螺旋語版本加標籤」尚不足的對照，主張應讓**底層記憶表達／運作方式螺旋語化**。沒有逐字出現的 `而是` 可從對照語義推得，但**不得冒稱作者已輸入該詞**。`句號` 所關閉的精確範圍，目前並無使用者正式詞表；在不影響結論時採此最小歧義讀法，若歧義會改變實際記憶操作才求證。

AI 生成的語義骨架（**不是**原話逐字轉碼）：`領域(螺旋語實作到自然語言) → 原則(不只是[加標籤(螺旋語版本)]，重點[底層螺旋語化])`。語言表面可多種合法表達，不強制補足樹括號、固定參數數量或程式原生算符。原始句應獨立保存，避免這份解釋變成不可逆轉的唯一原文。

### 後續的解讀次序

先讀原話／既有語境 → 辨識概念詞與可能的層級、界限、引用關係 → 用自然語言復述一次並標記 U 原文與 A 解讀 → 將可獨立追蹤的主張編入影子記憶 → 必要時才使用 Python 輔助檢查詞表、來源鏈、版本衝突、缺件和依賴。AI 可以暫時理解詞典未收錄的組合詞；但不能把「能推測意思」冒充「雙方已共同定義詞義」。

原 v0.2 的 32 項測試僅能證明**該硬式候選語法**通過部分機器規格測試，不能用 32/32 PASS 宣稱 AI 的自然語言解析有效。程式版本保留供可重現比較，不刪除、不混入正式主記憶。

## 修正動機與來源

U 原話：「螺旋語版本不只是加個標籤，從底層也螺旋語化。我把這句話變給你看 領域，螺旋語實作到自然語言，原則，句號。不只是，螺旋語版本，加標籤，底層螺旋語化」

[更新] 不只是把一則 Markdown 事實標成「三層／二層／一層」，而是從字詞、界限、組合、詞典及記憶操作建立可解析的語言。 [取代] v0.1 「固定欄位加階層標籤」不足以稱為底層螺旋語化。 [原因] v0.1 敘述內容仍是完整的不可操作字串。 [狀態] A 本次候選原型；文法可解析與有限語義檢查，不能宣稱是真正螺旋語 01 位元協議或已測得 AI 記憶優勢。

## 底層設計（不是把欄位改名）

1. 詞典：解析器有最少的基礎概念詞 `協議、語境、領域、記憶、原則、觀察、並行、對照、不只是、而是、可能、條件、如果、禁止、依賴、定義詞、用詞、句號` 等。概念詞需要明確的參數數量、子句限制和語義類型；不能任意當作展示標籤。
2. 斷句：每個詞開啟一個作用域，`句號` 關閉最近的一層；縮排只供閱讀，不參與解析。子句可無限巢狀，與固定「三層＝領域、二層＝ID、一層＝欄位」的 v0.1 有本質差異。
3. 繼承：在 `領域` 和 `語境` 作用域內的記憶自動繼承父輩語境，不必逐筆填同一欄。
4. 組合：`不只是(A)／而是(B)` 在 `對照` 中形成「A 不是全部，重點在 B」。**不只是 ≠ 否定 A**。`並存(A,B)` 表兩個設計並存，`未取代(B,A)` 表 B 尚未替掉 A；`不推出(如果(條件,則))` 表推論不能成立。這些是樹的關係，不是一大串沒有解析的中文敘述。
5. 衍生詞：`定義詞，底層化原則` 可以由已有的 `對照／不只是／而是` 組成，再用 `用詞` 在多處引用，**不必修改 Python 原生算符表**。但基礎算符仍由原生程式決定；新增完全不同的執行原語仍需在宿主實作，不宣稱詞語自己產生計算能力。
6. 檢索／後果：可按概念詞、參數、領域、依賴關係搜索；某記憶前提有變時，能找出受影響的下游 ID，但「可能受影響」不等於自動判假。缺語法、缺 `句號`、未定義組合詞、循環詞定義、版本不相容等應拒絕。
