# 自然語言螺旋語記憶｜平行實驗 SNL-MEM-0.1

日期：2026-11-02　｜　類型：獨立、唯讀來源、可重現的影子記憶實驗

## 目標

檢驗自然語言版本的「螺旋語」是否有助於跨領域研究記憶的結構、追溯、版本變動與後續擴充。**這不是螺旋語的位元編碼、也不是聲稱使用者定案的語法。** 目前只是根據使用者可演化階層詞典概念，由 AI 提出的記憶應用原型。禁止把原型測試 PASS 當成跨 AI 學習或長期記憶優勢。

這是和既有 `/AI研究記憶/` 主記憶相互獨立的平行實驗。原始檔案仍是權威來源；本資料夾僅含同一日期抽取的一小批快照資料。**不寫回主記憶、不清理或刪除原檔、不自動公開。**

## 階層如何用於記憶

語層不是主系統 L0–L4 記憶優先程度。此實驗用：三層定義研究領域與解析語境；二層定義穩定識別的概念／命題；一層定義可重複的語義角色（命題、狀態、證據、來源、依賴等）。語境、詞典和別名可以共用、由父層繼承。

```text
語法｜自然語言螺旋記憶｜SNL-MEM-0.1
語義快照｜S1｜2026-11-02
映射快照｜自然語詞｜M1
同義｜狀態｜現況
同義｜命題｜主張

三層｜研究領域｜螺旋語｜語境 S1/M1
  二層｜設計｜H006
    一層｜主張｜分層詞長方案 A 與全域等長方案 B 並列競爭，B 尚未取代 A。
    一層｜現況｜未定案
    一層｜證據類型｜U
    一層｜來源｜fixture://spiral/design
    一層｜時點｜2026-11-02
    一層｜關鍵詞｜詞典
```

上例是為人閱讀精簡的展示；機器檔案中 H006 的命題等資料以較精確完整的內容為準。不同表達「主張／命題」「現況／狀態」可經版本化詞表正規化；一筆記憶可引用其他 Hxxx，前提變動時沿依賴圖找到待覆核的下游。這不是依賴失效就自動判定它為假。

## 檔案分工

`自然語言螺旋記憶.snl`：試驗語法的完整影子記憶。

`一般Markdown對照.md`：同樣 14 筆、**保留完整相同欄位及依賴**的普通 Markdown；避免人為削弱對照組。

`共同事實基準.json`：手動核對、共用的測試答案資料；只供建立公平工作負載，不能當作 AI 自行發現的全量記憶。

`比較測試.py`：兩個獨立解析器、查詢及反例測試；`build.py`：從同一份指定事實建檔（重新執行會重生影子資料，勿當作正式更新機制）。

`機器測試結果.json`：可重現的解析與比較結果；`比較報告.md`：評估、限制與下一輪測試設計。

## 版本語義

現階段 S1/M1 為宣告標籤，解析器能拒絕錯誤的語層、陌生詞、未定義依賴、循環及部分別名衝突，但**尚未對詞典快照做不可變內容驗證**。不能把 `S1/M1` 當作已完成的密碼學語義錨點。檔案若離線移走，也要保存解碼詞典與來源連結。

## 如何重現

使用 Python 3（標準函式庫即可），在本資料夾執行：

```bash
python 比較測試.py
```

測試會重新寫 `機器測試結果.json`，不碰 Library 主記憶。若需重生影子輸入，先以備份確保沒有新的手動資料，再執行 `python build.py`。建議永遠先保存本批的證據快照，以免當天原資料已更新卻仍被標成 2026-11-02 版本。

## 下一步：公平比較而非預設勝利

第一階段只確認兩種格式都可還原相同資料、引用關係和不確定狀態；第二階段應交給**互不見到基準答案**的 AI 視窗分別閱讀兩種表達，使用相同題目、相同工具與閱讀預算，測回答正確率、來源定位、過時狀態誤判、編輯增量、文字／token／CPU 成本。第三階段才擴大到 100、1,000、10,000 節點、跨版本變更、不同來源分支及未知新詞。若結果顯示一般 Markdown 足夠好，應保留這個負面結果，不為了螺旋語強行加更多標籤。
