# 緊湊題目記憶樹：客體指標運算成本優化與同歷史重播

日期：2026-11-02（Asia/Taipei）。依據 `/倉鼠世界/工作入口.md` 接續；本檔中「本輪」只指本次一般對話的程式修改與實測。

## 來源與改動

U：使用者先前提出「題目只占必要樹節點，試答案可用排序／子樹等方式保存」的方向；本次指示「喔喔，原來是我自己的方案。你繼續」。本輪未將此設計重新歸給 AI。緊湊 12 位附帶資料與樹節點格式為前版成果，**本輪沒有重新發明布局**。

A/F：修改 `src/tree_compact_reference.hpp`：

1. `tree_compact_guest_at_work`：原 `TreeFourCode::at(3,pos)` 需反覆 `SMOVE_PTR` 走遠距離；改用 `MOVE_PTR` 以六位（固定 5+1 word）為倍數先走，再用 `SMOVE_PTR` 處理剩餘位元。guest 仍自己依節點 ID 定位；宿主沒有替它算答案或寫入附帶資料。
2. `tree_compact_guest_address`：把每個節點權重 `12` 的多次 bit move 改為可分段的 word move。此版僅支援現行 5+1 詞寬，並非通用詞寬的已驗證優化。
3. `tree_compact_guest_write_program`：答對時先定位到答案 3 位的起始位置，一次連續寫入，再退回成功旗標位，最後發布成功；不再四次重新查節點位址。錯誤答案仍只寫對應旗標。
4. `src/tree_compact_world.cpp`：客體的 `choice` 程式本已讀入整個 12 位附帶資料，主世界作答後直接沿用客體寄存器 8 的已學狀態，不額外叫一次 VM 讀取。
5. 新增 `tests/test_tree_compact_optimized_cost.cpp`，在相同題目／回饋／重訪歷史比較現在的舊式答案節點與優化的緊湊方案；新增 Makefile `tree-compact-optimized-cost-test`。`test_tree_compact_reference.cpp` 增加已學旗標以及後代繼承斷言。`test_tree_compact_world.cpp` 增加回歸成本上限。

本輪沒有修改 ISA、樹/附帶資料的記憶格式、世界題目和獎勵安排，也沒有加入語義公式學習、自由病毒市場或 Zero 世界功能。

## 新獨立測試與舊版基準

以同一六階段題目序列、正解與回饋歷史（15 次試答、11 次首次寫入、4 次已學重訪）比較。舊式答案節點的測試流程不變；緊湊方案不再多做已可由 `choice` 直接取得的讀取，因此計算的是兩方案**當下實作的端到端 VM 成本**，不是完全同指令流程的理論優劣。

| 指標 | 舊式答案節點（未改） | 緊湊前版（2026-11-02 已封存結果） | 緊湊本輪優化 |
|---|---:|---:|---:|
| 使用節點 | 13 | 2 | 2 |
| 已用資料位元（不含暫存/程式） | 117 | 42 | 42 |
| 預留資料位元（31 節點） | 279 | 651 | 651 |
| VM 呼叫 | 41 | 67 | 52 |
| VM 總步數 | 2,326 | 7,393 | 1,774 |
| 單次峰值步數 | 203 | 598 | 84 |

本輪同步重編 `test_tree_compact_differential_cost.cpp`，保留額外明確讀取，測得緊湊版 `2,599` 步／`67` 次呼叫；此測試與本輪優化版區分。由 7,393 降至 1,774，約減少 76.0% VM 步數；相比舊答案節點 2,326，少約 23.7%。資料位元 42 對 117，少約 64.1%，**但 31 個節點滿額預留位元仍是 651 對 279**。不得忽略預留開銷。

### 四倉鼠世界新舊版本同條件執行

將上一輪保存的 ZIP 中 `src/tree_compact_world.cpp` 用 `g++ -std=c++17 -O0 -g0` 編譯為基準，再用同一編譯參數編譯本輪程式，執行預設四倉鼠／11 輪世界。兩份輸出的每一輪 `round,question,mastered,correct,resource` 逐行**完全一致**：第六輪升階，最後四隻全學會、資源總額 3,600、使用 8 個樹節點。

| 世界計數 | 前版（已在本輪重新編譯執行） | 優化版（本輪） |
|---|---:|---:|
| VM 呼叫 | 260 | 216 |
| VM 步數 | 32,189 | 8,689 |
| 單次峰值步數 | 598 | 84 |
| 已使用題目節點 | 8 | 8 |
| 預留樹欄／附帶位元 | 1,116／1,488 | 1,116／1,488 |

總步數降約 73.0%，呼叫數降 44 次；是同工作流目前程式的計數，不等同物理 CPU 時間、能耗或自由生態效率。優化版少了 VM 冗餘讀取是刻意的，兩版不是逐指令完全相同。

## 測試覆蓋與限制

T：`-std=c++17 -O1 -g -fsanitize=address,undefined -fno-omit-frame-pointer`，重編並執行 `tree-compact-optimized-cost-test`、`tree-compact-differential-cost-test`、`tree-compact-reference-test`、`tree-compact-world-test` 和 `tree-error-trial-test` 均 PASS；後續也用 `-O0 -g0` 新舊獨立編譯世界、輸出逐輪完全一致。`tree-compact-reference-test` 驗證題目 1～7、最後節點 ID 31、錯誤旗標、成功答案、已學狀態和後代繼承。

`tree-error-world-test` 在本輪一次執行中於編譯階段逾時，**未列為 PASS**；既有舊版的 PASS 是另一輪紀錄。未重跑長期 HP 生存、6000 個隨機 VM 客體、完整 652 題或 Zero 世界，也未測牆鐘效能。固定 5+1 詞寬下的 `MOVE_PTR` 倍率不可直接轉移至其他 ISA 格式；新功能仍需要跨詞寬重寫/驗證。

## 更新與接續

[更新] 緊湊記憶樹在同歷史實測中能同時降低「實際使用的資料位元」與「當前 VM 步數」，單次峰值也降低。
[取代] 上一輪只看到緊湊方案比舊式多花 3.18 倍步數，尚未優化。
[原因] 遠距指標移動與答對時四次重算位址是可消除的實作開銷；重複資料讀取也可改用客體本已取得的旗標。
[狀態] 高（上述固定題組與固定四倉鼠世界有可重播 log 和測試）；大型世界、其他詞寬與資源模型的長期比較未知。

下一步：優先測試在更多題目與容量、不同錯誤分布、有限記憶體配置、後代與壽命條件下的總成本；要另外報告程式碼長度、位元預留與宿主調度。不要因這一小型對照的勝利就宣稱螺旋語或記憶樹普遍高效，也不急著改為公式記憶。
