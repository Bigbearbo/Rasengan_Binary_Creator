# AE1：五階符號高級回音的有界 codec／fixture

這裡實作純程式格式檢查，沒有神經訓練或推論。基底為 Codex `365c5fbf3324d3decb625f9d04ddd1bc91af4d93`。所有新增檔案限於本目錄，舊 learner、cap、Neg 語義和歷史證據保持原貌。

## 來源與範圍

**U**：使用者提出 `01 + 高級回音 010 + 回音長度參數 + 多個五階符號 + 句號`。

**A**：Pro 將本次設計限定為獨立 profile `SLE-AE1-n5-v1`；固定欄位、`N=1..4`、保留兩個控制碼及拒絕規則如下。初階 `full_echo` 用 `r=N`；第二階 `prefix_echo` 允許 `r≤N`，其中 `r<N` 是 Pro/root 的延伸，不冒稱使用者已明說此課程。

**F**：本目錄保存上述 profile 的 codec、固定例題與檢查入口。不得以 `010` 在這裡的意思覆寫 legacy Neg。呼叫端必須明確提供 profile，codec 不猜版本。

**T**：`checks.json` 是實際執行 `check_design.py` 的結果；`fixtures.json` 中四題由 codec 生成，再與程式中的固定 raw 位串逐字核對。這些 T 只支持此有界格式及測例，不支持神經網路已學會回音。

## 固定文法

| 欄位 | 位元／規則 | 長度 |
|---|---|---:|
| 開場 | `01` | 2 |
| 高級回音算符 | `010`，只在 AE1 已知 profile 下解釋 | 3 |
| 回覆詞數 r | `bin3(r) + 0`，`1≤r≤N`；r 不是輸入詞數 N | 4 |
| payload | N 個 `bin5(ID) + 0`；`N=1..4`，普通 ID `0..29` | 6N |
| 句號 END | ID 30：`111100` | 6 |
| 保留 UP | ID 31：`111110`；不能作本題普通 payload | — |

所有 payload 都是 opaque 符號，不執行其值可能代表的算子。解析只在第 9 位元之後的六位元詞界上判斷 END／UP；不掃描內部的 `100`、`110` 等短子串。END 只能出現在末尾，後面有任何多餘位元均拒絕。

答案 A 僅為前 r 個 payload 的原六位元詞，沒有開場、算符、count 或 END。其後輸出外部 **STOP 動作**；本目錄以 `S` 顯示該動作，`S` 不進入 Q／A 位串，也不是新的 01 詞。把 `S` 塞進 Q 會被拒絕。

## 固定例題

四詞 ID 為 `[1,6,11,17]`，同一 payload body 在 `fixtures.json` 提供 `r=1..4`。以下空格／豎線只作閱讀分欄，不屬於實際輸入。

```text
Q(r=4) = 01 | 010 | 1000 | 000010 001100 010110 100010 | 111100
A(r=4) = 000010 001100 010110 100010 ; 外部 STOP
A(r=1) = 000010 ; 外部 STOP
A(r=2) = 000010 001100 ; 外部 STOP
A(r=3) = 000010 001100 010110 ; 外部 STOP
```

改 r 時，Q 的 count 欄也要改；不是將同一完整 Q 配上互相矛盾的四個答案。範例詞 `001100` 和 `010110` 本身含 `100`／`110`，不能在這些內部位置截斷。

## 長度與既有 learner 邊界

`|Q|=2+3+4+6N+6=15+6N`，`|A|=6r`。合法最大 Q 為 39 位元、A 為 24 位元。最後一個 teacher prefix 是 `Q+A`，下一動作是 STOP，所以最大輸入 prefix 為 **63 位元**，L80 能容納。完整正確生成最多 **25 個動作**，包含 24 個答案位元及 STOP。

因此舊 cap24 放不下最長正確生成；本設計建議若日後開新 learner，另明訂固定 **cap32**。若錯誤生成一直不停止，第 32 次動作前最多已有 31 個答案位元，輸入最長為 `39+31=70`，亦在 L80 內；這是生成上限的算術推論，沒有執行神經生成。本次沒有改動舊 learner，也沒有啟動新 learner。這只是已知格式長度可容納，不是模型可學會的證據。

## 整題 prefix-free 與教師標籤一致性

在已知 AE1 profile 下，所有 Q 的前九位元欄位固定長度。不同 r 已在這九位元內不同，不能形成前綴關係；r 相同時，假設較短 Q 是另一題的前綴，其 END30 必在對方的相同六位元詞界上。若對方還有 payload，該位置必須是普通 ID0..29，不能同時是 END30；若也是 END，兩題在同處結束。因此**不同合法完整 Q 互不為前綴**。

任一 teacher prefix 形如 `Q+A[:i]`，`0≤i≤|A|`，標籤是下一個答案位元，或 `i=|A|` 時的外部 STOP。若兩個 teacher prefix 位串完全相同，兩個 Q 都是該位串的前綴；由整 Q 的 prefix-free 性質，它們必是同一 Q。兩個 i 也相同，而 A 由 Q 唯一決定，所以不會出現同輸入、不同下一動作的跨題衝突。

這是格式上可定義單一函數的證明，不是有限 MLP 的學習、容量或泛化保證。它也依賴已知 profile、固定欄寬、保留 END 及無損位元輸入；不延伸到未知版本混用。
