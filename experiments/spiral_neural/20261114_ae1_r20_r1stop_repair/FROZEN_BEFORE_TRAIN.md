## Causal question and exactly one semantic variable

R19 wrongly sent r=1 STOP (cursor 6) through second-word-only mask, despite a frozen claim STOP was unchanged. At fixed 10457-parameter model, same 136 native-01 teaching appearances (112 distinct, 1408 target-prefix pairs per epoch), same initial state, seed, train schedule, data and evaluation, **alter only second-route predicate** to include the visible raw header condition r=2.

Frozen exact patch to R19 `experiment_r19/run_r19.py` `DualRoutedStudent.forward`:

```diff
- second=((cursor>=6)&(cursor<12)).reshape(-1,1,1)
+ second=((cursor>=6)&(cursor<12)&(z[:,6,1]>0.5)).reshape(-1,1,1)
```

`z[:,6,1]` denotes one-hot raw bit at Q position 6: 0 for r=1, 1 for r=2, under frozen `SLE-AE1-n5-v1` question profile. Thus r1 cursor6 STOP uses all four data-word inputs; r2 positions6..11 retain b-only route, and r2 cursor12 STOP uses full input. All else is the same neural mathematics; bookkeeping names and evidence paths differ.
