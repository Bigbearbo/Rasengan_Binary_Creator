# Seven-bit fixed-multiplier output diagnostic

Run: pro_mul3_error_fingerprint_20261120_v1. Independent static arithmetic experiment. No neural training, inference, weights, or claimed neural mechanism. This protocol fixes the seven synthetic functions before running the panel search. The existing order-study summary and the XOR/OR identity were known when choosing these questions. Probe inputs are illustrative, not fresh held-out tests.

Input x is every integer 0 through 127 inclusive. Output is a decoded nonnegative integer, with arithmetic over full integers except for explicit truncation. Use y = 2x, propagate mask p = x XOR y and generate mask g = x AND y. The hypotheses are true_mul3 (x+y), double (y), xor (p), or (x OR y), one_carry (p XOR (g << 1), carry bits reach the next column but new carries from adding them are discarded), trunc7 ((x+y) mod 128), and trunc8 ((x+y) mod 256). These rules are illustrative reference functions. A match applies only to that output.

For each x record all seven outputs, whether any initial carry is generated, and exact agreement with the correct full product. Compare the 21 pairs on their numeric answers and separately on just their correct/incorrect pattern. Enumerate the shortest exact panel distinguishing all seven rules: try all singletons and pairs in lexicographic order. Then make a panel whose outputs across questions have Hamming distance at least three for every pair of rules, so one arbitrary numeric replacement is correctable given a single fixed rule. Prove the minimal number of questions separately using the truncation intervals. Select the first three maximally discriminating rows in each of the two intervals needed for that proof, if available; explicitly verify the distance and whether the bound is attained. Recompute with an independent column-based addition algorithm.

Project aggregate analysis: compare the published 5/9 plus 4/27 (random order) and 2/9 plus 0/27 (low carry first) against numeric baselines, conditional on properly submitted valid baseline answers. Report absence of numeric answers separately; all numeric baseline ties must remain ties. Do not infer the neural algorithm, fit new rules to per-item held-out mistakes, or alter the training stream.
