# SLE AE1 原生 01 小網路：高詞值答案位置互換實驗

2026-11-13，獨立 NN 研究；**真正新訓練**，與 VM 核心、parser 詞典、UR1 升階通知分開。

## 問題與前置凍結

PR #34／#35 的四份舊模型對第二答案詞 b=6..29 幾乎不能完整答對，且 b 的高位 8/16 未被輸出。但這混雜了「詞值根本沒學過」與「詞值沒有在第二答案位置學過」。這次不重新分析舊結果，而是直接訓練新四學生進行配對控制。

* 事前承諾已先寫入 commit `8cc0cfe6011300cc0ca54fe2f8900b3c969725db` 的 `protocol.json`，**之後**才啟動一次正式訓練。
* 唯一訓練政策差異：合法高詞 ID6..14 出現在第 1 個回覆詞 `HIGH_FIRST`，或第 2 個回覆詞 `HIGH_SECOND`；兩側相同低詞、題量、學習率、seed、初始完整權重、更新次數、shuffle 索引及容量。**高詞移動位置會連帶改變輸入欄位及答案前綴位置，因此不是保持 raw bit 輸入不變的消融。**
* SLE-AE1-n5-v1：`Q=01+010+r(3bit+0)+4×(5bit+0)+111100`，39 位；`A=前r個完整詞+外部S`，r∈{1,2}，ID0..29合法；30=END、31=UP保留。沒有把真答案、外部 parser 或教師 oracle 塞進 NN 輸入。
* 共同基準：a,b=0..5，`(a+b)%6` 分割為 24 train／6 val／6 test 配對，每配對教 r1+r2。
* 補充教材：v=6..14，s=0..3 共36組；第一位置臂教(a=v,b=s)，第二位置臂教(a=s,b=v)，只教 r2。
* 未教組合：s=4..5，v=6..14，各方向18題；兩臂都未訓練過這些配對。c=d=0 固定，排除無關後綴干擾這一維。
* Seed101/202 ×兩臂共4模型；各10,499參數，160槽one-hot→64 tanh→3 logits，Adam .003、batch64、clip1、250 epoch。每學生 948 targets/epoch、3750 optimizer steps；全部合計 **15,000 updates、948,000 target exposures**。不調參、不中途挑最好state、不延長。

事前 fixture：
```text
Q(r2,a0,b6,c0,d0) = 010100100000000001100000000000000111100
A                  = 000000001100S
Q(r2,a6,b0,c0,d0) = 010100100001100000000000000000000111100
A                  = 001100000000S
```

## 實際訓練 T：高詞值**只在受教的輸出位置有效**

| Seed／學生 | 已教自己方向 | 保留 HIGH_FIRST (18) | 保留 HIGH_SECOND (18) | 原域train／val／test |
|---|---:|---:|---:|---|
| 101 HIGH_FIRST | 36/36 | 18/18 | **0/18** | 48/48、12/12、12/12 |
| 101 HIGH_SECOND | 36/36 | **0/18** | 18/18 | 48/48、12/12、12/12 |
| 202 HIGH_FIRST | 36/36 | 18/18 | **0/18** | 48/48、12/12、12/12 |
| 202 HIGH_SECOND | 36/36 | **0/18** | 18/18 | 48/48、12/12、12/12 |

交叉評估已教的低詞 s=0..3 也相同：自己方向36/36，未學的另一方向0/36，無法用「只是未見配對」解釋。所有試題皆自行生成STOP，全部輸出與長度按檔保存。

實際失敗 raw bits 例（seed101，同一題在不同教學方向下）：

```text
Q(second high a4,b6) 010100100001000001100000000000000111100
正解                 001000001100S
HIGH_FIRST 錯答      001000001010S
HIGH_SECOND 正答     001000001100S

Q(first high a6,b4)  010100100001100001000000000000000111100
正解                 001100001000S
HIGH_FIRST 正答      001100001000S
HIGH_SECOND 錯答     111000001000S
```

**這個結果的範圍非常明確**：小網路有能力將合法高詞正確輸出到已受教的位置，並將這種位置相關能力組合到未教的低詞配對；但不能自發把同一高詞詞值遷移到另一個答案位置。這個觀測不證明模型完全沒有 bitwise copy 線索，也不能說 SLE 比其他輸入語言差／好。
