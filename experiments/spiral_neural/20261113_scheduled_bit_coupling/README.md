# AE1 第二答案詞：失敗整串下仍有低位元反應（獨立診斷）

日期：2026-11-13。來源 [PR #34](https://github.com/Bigbearbo/Rasengan_Binary_Creator/pull/34)，**固定其 head `23963d32f0ef75c5890cfdd5bc9d320621754f32`、`raw_cases.jsonl` blob `62f6d95bad4abf3dc57a6852eb990be9bcabd96d`**。本實驗屬 NN 教學／泛化資料分析，不修改 VM、詞典、UR1 與任何別人的研究分支。

## 目的與預先記錄

前批 PR #34 已確認 b=6..14 時 r2 整題僅 1/216 正確，b=15..29 時 0/360。本輪新問題是：**整個詞不對時，第二答案詞的哪幾個資訊位仍會隨第二輸入詞 b 變化？** 若只看 exact，會把「完全無視 b」與「低位跟著變，但高位根本不能輸出」混在一起。

先以 [protocol.json](protocol.json) 於提交 `af21c6515b699638ef4d60ede5dbac5112bf0ef0` 記錄唯一變因、分組、逐 bit 一位元差異邊、負控制、固定 4 模型與驗收門檻；之後才實際讀取逐筆輸出計算。本輪為**已觀察過整串分數後的回溯診斷，不是新的盲測**，也沒有新模型 forward 或訓練。來源的四份模型為 seed101/202 × fixed/varied，均 10,499 參數；原訓練 24/6/6 (a,b) split，200 epochs × 每模型 1600 optimizer step，見 PR #29 與 PR #34。

原生合法 `SLE-AE1-n5-v1`：`Q=01+010+r(3資訊位+0)+四個(5資訊位+0)+111100`，39 bit；r=1,2，資料 ID0..29；答案取前 r 個六位元詞加獨立 `S`。二個 r 組只改 b、固定 a/c/d/權重。完整題目與預測保留在上游 [raw_cases.jsonl](../20261113_scheduled_b_vocab_transfer/raw_cases.jsonl)，本分支只保存程式與摘要而不重複 1440 列。

原生 raw bit 範例（a=0,b=6,c=18,d=26,r2）：
```
Q        010100100000000001100100100110100111100
expected 000000001100S
actual   000010000110S  (seed101 fixed)
```

## T：實際獨立執行的離線診斷

使用 GitHub connector 取回**真實** 1440 筆 `Q/expected/actual` 與 blob，於隔離 JS/V8 計算 `analyze` 函式；所有合法 Q、答案、唯一 model×a×b×r、固定長度/STOP、PR34 已報數字均通過 gate。每一個 (seed,mode,a) 固定上下文中，取同一組內 b 與 b xor (1<<k) 的 **合法單 bit 輸入差異邊**，檢查第二答案詞相對應資訊位是否 0→1（正向）、1→0（反向）或不動；r1 第一答案詞為負控制。**這不是重新跑神經推論**。

| b 詞域 | r2 第二詞資訊位正確／總位數 | 同詞域多數位基線 | r2 一位差異邊：正向／反向／不動 | r1 第一詞被擾動邊 |
| --- | ---: | ---: | ---: | ---: |
| 0..5，第二答案角色見過 | 656/720（91.1%） | 552/720（76.7%） | 129／14／25（共168） | 2/168 |
| 6..14，可能只作過 c/d 後綴 | 708/1080（65.6%） | 744/1080（68.9%） | 140／29／95（共264） | 59/264 |
| 15..29，訓練時整體未見 | 842/1800（46.8%） | 1104/1800（61.3%） | 191／116／293（共600） | 174/600 |

「多數位基線」是各 b 詞域的逐位常數最佳預測，不是另一個 NN。邊數包含六 anchors × 四模型，**不能當作 168/264/600 名獨立學生**。兩個 seed 在 6..14 的正向減反向分別為 +55、+56；15..29 為 +37、+38。跨 24 model-anchor 上下文，6..14 為 23 正／1 零／0 負，15..29 為 18 正／2 零／4 負；同 seed 與同模型內高度相關，沒有作 p 值主張。

### 最大的新可辨結果：高資訊位沒有被寫出來

在 720 個 r2 第二答案詞中，模型只輸出了 **七個 ID：0、1、2、3、4、5、6**（分布 55、79、153、95、196、140、2）。第 8/16 權重資訊位皆為 0/720 個 1，整個資料集沒有生成 ID≥8；六位元結尾 0 與外部 STOP 都是 720/720 正確。

因此 b=8..29 的 528 個 r2 失敗**由輸出詞值範圍直接確定**，不是需要歸咎於生成停止、整句長度或高位之後的累積錯誤。b=6,7 的 48 個 r2 尚在模型輸出值範圍內，卻也只答對 1/48。其餘 115 個正確都來自 b0..5。

低位並非完全不動：在全未見 b15..29 的逐 bit 配對中，輸入資訊位 k=2 的 144 條邊，輸出對應位正向 85、反向 0、不變 59；但 k=0 為 54 正／66 反，k=1 為 52 正／50 反，k=3 全部不動。這表示**本批固定模型對部分輸入位仍有局部敏感性，卻不能轉成高位完整詞**；可能與既有教材的輸出值分布及角色學習有關，不能單憑此辨識內部演算法。

重要限制：模型在**這批固定 Q、兩 seeds、四 checkpoints** 中沒輸出 ID≥8；不是宣稱對所有輸入永遠做不到，亦不能把 0/360 推論為 SLE 的一般性失敗。PR34 b6..14 與 b15..29 同時改了詞值分布、位置曝光及詞的角色，因果仍未隔離。
