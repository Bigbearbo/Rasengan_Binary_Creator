# 三詞回音：先設計，再做一輪學習探測

2026-11-13，Codex。此設計在本輪任何正式神經網路推論／更新之前保存，待來源、程式與輸入封存、獨立檢查及Git回讀後，才執行一次CPU命令。

PR43只證實學習率0.001能讓三個已會模型在下一輪保住舊題，尚未測試新增教材。這輪問：加入三詞回音後，0.001能否保住舊能力並增加新題整串正確數？同時用完全相同起點與課序跑0.003，逐seed呈現學新與忘舊的取捨。這是固定一輪的學習探測，不以一輪未全對判斷E3學不會。

起點是PR43結果995870a458e4c9da279b30b03e39c6097dce9cc7的三個final-after-TF完整存檔，t分別1017000／1228500／1161900。載入p/m/v/birth/t/RNG/events及全部計數；每個seed的兩臂從同一baseline-end完整state各自複製，不接續另一臂的訓練。

仍用900組既有N4 payload、L80/H64、10499參數與原NumPy CPU。舊3600道Q/A逐byte保留，新添900道E3：Echo操作碼010，參數從1、2延伸為3（0110），題目payload與順序不變，答案是前三個完整詞。每詞5個資訊bit後接0，再輸出外部S。例如payload[1,6,23,11]，E3答案為`000010 001100 101110 S`。Q長39，E3答案18bit加S，STOP教師前綴長57，都在L80內。

每seed以seed+666000產生唯一target洗牌，兩學習率臂使用同一順序。正確答案前綴的逐bit交叉熵、原Adam、clip1與birth-age修正全部保留。兩臂唯一差異是Model.step的學習率常數0.001／0.003；不調格式、精度、容量或梯度規則。每臂恰53100更新，各一輪；六臂共318600更新、6708441600 training dense MAC。不追加epoch、換seed、挑checkpoint或依結果改學習率；完整optimizer重播設為0。

正式命令先讓三個模型的舊3600道自由生成全部與父存檔一致、四類各900全對；任一起點失敗則全批在任何optimizer前中止。再計每seed一次E3冷生成900題與E3全17100位置的baseline TF，僅改推論計數。三份共用baseline的實際成本只記一次，複製到兩臂的計數不能重新計費。冷E3分數不假設為0。

六條訓練各自完成後保存完整state與4500道自由生成；全六條primary完成才做六份最終TF，各53100 targets。生成只接自己的答案，沿用cap32、L80 guard與第一個S停止，不按正解長度截斷或強迫S。保存全部raw tokens、flags、QID、預期答案，以及TF prefix／label／logits／probabilities／CE。

事前主要可行性判準是0.001的三個seed都同時滿足：舊3600題流失0，E3整串正確數嚴格高於各自冷分數。0.003也報相同旗標；逐seed列兩臂的舊題流失、新E3絕對分數／增量與逐QID交集。主要旗標不能代替兩臂比較，也不能直接證明0.001較優。若冷E3已900，嚴格增益仍照公式計算，但標baseline-ceiling、學習增益不可識別，不稱為學習失敗；不因天花板換題或延長。

額外讀數從保存tokens直接算：五類整串、每詞（含第三詞）的5資訊bit／補0／完整6bit、各位置bit、STOP、首錯及終止型態；不為這些統計再呼叫NN。TF與自由生成分列，正確前綴下答對不能當作真實整串生成成功。

獨立驗收限一次raw NumPy：三份baseline全部自由生成與E3 baseline TF、六份終點自由生成與最終TF，零optimizer；核對完整state／來源／ZIP／計數與前後hash。自由生成比tokens／flags／scores，逐值logits／probabilities／CE核對專指保存的TF位置。中間gradient／逐target loss／權重軌跡沒有獨立重播。

限制是三個已看過payload、事後挑選的繼承state與一輪有限教材；不是盲測、未見題泛化或長期最佳學習率實驗。Git最新PR44／45是另一PyTorch cohort，不混入本研究。E4及更長訓練不在本輪。NVIDIA一次公開／合成候選的兩個總成本算式錯誤，未採為研究事實；Gemini因原有analysis-only工具隔離未解而明確略過，未重送／重登入。
