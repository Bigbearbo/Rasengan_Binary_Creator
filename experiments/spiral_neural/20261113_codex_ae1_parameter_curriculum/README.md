# 新回音：同題先參數1，再參數2

2026-11-13，Codex。正式神經訓練尚未開始；此事前版本保存課程、完整初態與全部可能使用的課序，執行結果另在完成後新增。

沿用公開 [AE1設計 PR16](https://github.com/Bigbearbo/Rasengan_Binary_Creator/pull/16) 的 `SLE-AE1-n5-v1`。題目是 `01 + 新回音010 + 回覆組數r + 四個資料詞 + END111100`。參數r使用三資訊位加尾0，1=`0010`、2=`0100`；每個普通資料詞五資訊位加尾0，ID0..29，END30與UP31保留。回答前r個完整資料詞，再自行輸出外部STOP；END不回覆。參數改變時，資料詞及順序完全相同。

```text
01 010 0010 000010 001100 010110 100010 111100 → 000010 S
01 010 0100 000010 001100 010110 100010 111100 → 000010 001100 S
```

空格僅方便閱讀；學生只讀原始Q與目前答案前綴，每次輸出0、1或S，沒有詞界特徵、游標、外部計數器或強制停止。

題庫有900組四詞資料。前兩詞列舉0..29的全部900種有序組合；後兩詞使用預先固定的隨機數。各r、各seed共用完全相同的900組，不把同長度答案組合挖洞作為保留題。這仍只教900組四詞輸入，並未窮舉30^4=810000個四詞組合，亦未測隨機換後兩詞的泛化。

|---|---:|---:|---|---:|
|r1|900題，全部r1|6300|連續兩輪900整題含STOP全對|40輪|
|r12|同900組的r1與r2，共1800題|18000|連續兩輪兩個r各900整題含STOP全對|40輪|

各輪把所有 `(QID, 答案位置)` 打散，使用正確前綴做交叉熵更新。每題各有完整target集合，但不按整題連續教。r12兩種r題數相同，target更新比6300:11700，沒有另外作長度平權。每個完整輪末才用模型自己的輸出測試；有任何整題錯誤即清零連勝。r1達標才進r12，達上限仍未過關則該學生停止，不補課、不換seed、不挑最好checkpoint。r12完整沿用r1的權重、Adam、步數與RNG。

三個新學生seed101/202/303。固定原P030 tanh MLP L80/H64、10499參數、Adam0.003，無grow、路由器或人工copy權重；原Model AST不改。Q39位，r1/r2正確STOP前綴45/51；生成固定cap32動作，最大待測前綴70≤80，不按正解長度截斷。保留r3/r4同文法相容性，本輪不訓練或探測。

每seed最高972000更新／20466432000 training dense MAC。三primary最多2916000更新，事前唯一指定seed101完整重播最多972000更新，其他seed明列not_planned。推論每次10432 MAC、訓練每target21056 MAC；推論、重播、工程及獨立audit另外計算。p/m/v/birth陣列209980 bytes不是程序RAM峰值。

每個實際epoch保存完整state、全部生成字串、分數、streak／停止判斷與逐target prediction/loss摘要digest。完整逐target原始列與中間gradient不保存，不聲稱獨立重算過未存資料。全部primary與唯一replay後才做最後teacher-prefix診斷，且只評該學生實際教過的r集合。首次觀測全對和兩連勝分開；只在輪末檢查，不能宣稱精確首次學會題數。

這是固定題庫、指定課程的學習與保持實驗，沒有盲測、平鋪課程對照或學習率對照，不單獨識別課程、題量或架構的因果效果，也不宣稱任意長度／內部通用copy算法。PR24的八資訊位數值Echo／Neg和本輪不同profile，沒有載入其權重或混用其010=Neg語義。
