# 早混與晚混的固定末段對照結果

2026-11-13，Asia/Taipei。Codex 實作與執行，受指派 agent 獨立核對。這是原 P030 固定三資訊位 profile 的新實驗，不是五資訊位 AE1。

**六個學生都學會已教的回音與翻轉題；早混沒有改善本批翻轉診斷分數。** 每個學生的 Echo、Neg 已教整串各6/6。未教完整題目的翻轉，早混與晚混都只有1/6答對；回音分別2/6及1/6。兩種操作合計早混3/12、晚混2/12，僅多出seed101的一次Echo正確，沒有穩定優勢的證據。

最後所有六個學生的首位操作碼對照都8/8：同一資料詞、空答案前綴，只改操作碼，第一個輸出能正確由複製改為取反。這只支持首位的條件操作，沒有識別獨立神經路由，也沒有保證後面資訊位同樣正確。

例如早混seed202的Neg題 `01 010 1100`，應答 `0010`再STOP，實際是`0110S`。首位已正確取反，後面的資訊位仍錯。六個最終學生合計96次作答的STOP位置均正確；TF尾零與TF STOP也各96/96。尾零及答案長度固定，這兩項可依格式線索完成，不能單靠它們認定會翻轉。

最終沒有錯誤答案剛好等於同一資料詞的另一操作完整答案。這與首位對照全對相符，不能再當成第二份獨立的路由證據。完整資訊位錯誤及自由生成／正確前綴的差異保存在逐題truth中。

## 同課量與共同末段

使用原P030 Model AST，固定L13/H69、2073參數；seed101/202/303各建立一對完整相同初態，沒有移植舊學生、grow、額外分隔符或路由器。Q為`01 + 操作詞 + 三資訊位資料詞`，每個詞保留尾零：`01 000 1010`的Echo回`1010S`，`01 010 1010`的Neg回`0100S`。S是輸出動作STOP，不是螺旋語資料詞。

每臂2400題次／12000次target更新；Echo與Neg各1200題次，每個(op,value)各200次。訓練值為0、1、2、3、4、7。兩臂每op內的完整值流相同，前1200題的完整多重集合也相同，末1200題的實際(op,value)逐題完全一致。

早混從最初兩題就各出現一種操作，前1200題Echo／Neg各600並依固定RNG洗牌；晚混先300題Echo，再將Echo300／Neg600混入900題。共同尾段均為Echo600／Neg600。相同總量不代表每個早期時點曝光相同；這比較兩條完整教學次序政策。

300題測點，晚混三學生的Echo各8/8，Neg尚未受教；早混的已教Echo／Neg分別3/1、2/1、1/3（各分母6）。此時兩種操作曝光不同，不能據此直接排名同曝光的學習速度。1200題測點，六個學生的已教Neg已全6/6；早混seed303的Echo仍5/6，最後才到6/6。固定測點只提供觀察區間，不是精確首次學會的題次。

只存0／300／1200／2400題次的state。所有六個primary及六條完整重播完成後，才離線評四點的全部16個合法Q；沒有分數決定的停訓、加課、換seed或挑checkpoint。中途也會退步，例如早混seed202的Echo診斷由1200題時1/2變成最後0/2，不能只選較好的中途分數。

## 歷史與泛化界線

1171參數的P027–P029只曾神經訓練Echo；P029的Neg例子是宿主oracle，不是學習成果。本次2073參數的已教翻轉成功不能冒稱1171已測過，也不能推定2073是最低容量。舊P030三個dynamic學生亦曾Neg已教各6/6、同一test值則各0/1。

P033早已在2595參數模型做相同完整初態／教材多重集合／每op值流的早混與後混。T1、T0B的已教題均成功，未教val+test分別0/24與1/24。本輪新增較小固定模型、2400題預算及完全共同的最後1200題流，並非首次earlymix；跨P033模型／分割／預算差異不能單獨歸因容量。

本輪的5／6早已在先前研究查看，屬曝光診斷，不是新盲測。它們作為題內資料值不參與本輪更新，但可能作為Neg的教師答案出現。全部16Q為相同固定長度，教師輸入無衝突；本輪不經跨階raw改碼，不將舊階碰撞誤算成新曝光。只有兩個未教資料值與三組配對seed，不能以這個小差值斷言早混無效或有效。

這批支持「小網路可擬合兩種操作」及「首位會依題型改變」；仍沒有可靠完整未教題的複製／翻轉，未唯一識別內部機制，也不回答長度外推或AE1多詞遷移。完整背景見RESEARCH_NOTE.md，已讀並行Pro PR19的AE1結果，本輪未重跑其課程。
