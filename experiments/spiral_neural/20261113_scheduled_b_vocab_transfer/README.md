# AE1 原生 01：第二資料詞 b 的跨詞域遷移（2026-11-13）

這是獨立小型神經網路工作，不改倉鼠 VM 核心、螺旋語詞典、UR1、Pro 或 Codex 的實作分支。核心研究問題：**已訓練的神經學生是否會在合法新資料詞上，把第二個輸入詞 b 真正複製為第二個答案詞？**

## 來源、凍結與一次變因

父分支 [PR #29](https://github.com/Bigbearbo/Rasengan_Binary_Creator/pull/29) 固定 head `dcabc3a65a4b9e7a50ab83ff8266b2c233d15000`。新分支 `research/scheduled-nn-ae1-b-vocab-transfer-20261113`，開始推論前先提交完整 `protocol.json`（commit `085cdd81d01fc4054bb43a055c8a69248641b823`），再提交真正執行的 `core.js`（commit `365bf179f0eb6f1de6e8f04415f0f5e1fc59a24b`，Git blob `c6fb4968c352ecc1f1a8827d81cee0b99f462b20`），才取得原始 checkpoint、執行 forward。其他公開結果是在事後保存。

凍結資料：PR29 的四份 *實際訓練* checkpoint，兩個初始 seed 101／202，各有固定／輪換無關後綴兩個訓練模式。每個小網路 10,499 個參數、one-hot 160 → tanh 64 → 3 logits (0、1、S)，PyTorch batch Adam lr .003、batch64、200 epochs、每網路 1,600 optimizer updates、96,000 teacher-target exposures。原訓練的 (a,b) 僅在 0..5，依 `(a+b)%6` 分 train24／val6／test6；後綴 c、d 的訓練值在 0..14。注意：這不是重新訓練；四網路固定，新增更新 **0**。

合法 `SLE-AE1-n5-v1`：Q = `01 + 010 + r(3資訊位+0) + 四個(5資訊位+0) + END111100`，共 39 個原生 01 bit；r=1 或 2，普通 ID0..29，30/31 保留為 END/UP；答案是前 r 個完整六位元詞，由小網路自行輸出外部 `S` 結束。輸入只含 01，學生未接收答案解析、詞界特徵或 oracle。

這次每個模型固定六組原 test anchor `(a,b0)`，其中 a=0..5 且 `(a+b0)%6=1`；固定 a、c、d、r，只變更**第二資料詞 b 的六個原生位元**，窮舉 b=0..29。c,d 使用原已評估的高後綴 `15+(7a+3b0)%15` 和 `15+(5a+11b0)%15`，避免再同時變動第三、第四詞。共 4 模型 × 6 anchors × 30 b × 2 r = 1,440 題；三段診斷 b0..5（作為答案詞曾出現）、b6..14（在訓練中可能當過無關後綴，卻未當第二答案詞）、b15..29（訓練輸入詞值未出現）。最後一段再排除 `b=c` 或 `b=d` 碰撞，單列 312 個 r2 配對。r1 是負控制：改 b 不應改變正確答案；r2 應跟隨新 b。這三段同時改變 ID 的分布與角色曝光，**不是「只改角色」的純因果對照**。

事前 gate：四 checkpoint 與 864 條封存輸出的 Git blob 必須和 `protocol.json` 列出的來源 SHA 相符；用無關模型程式碼的原生 float32 dense-tanh 實作先全數重現 **864/864 原始自由生成輸出**，否則不得執行新 1,440 題。接著逐題檢查 profile、Q39 位、a/c/d/r 不變與 b 槽位置。結果中不得丟棄任何 seed／失敗題。

## T：真正執行的結果

此次是在 GitHub connector 取回已提交 `core.js`、公開模型檔與封存輸出，於隔離 JS/V8 執行，同一份已提交核心程式真正進行神經前向推論；不是本機 Codex、不是教師 LLM 代算答案，也不是照報告重抄統計。先 864/864 archived reproduction gate PASS，再算 1,440 筆新輸出。**所有 1,440 題都在正確的輸出位置停止，但內容泛化劇烈失敗**：

| b 的 ID 範圍 | r=1 完整正確／分母 | r=2 完整正確／分母 | r=2 第一詞正確 | r=2 第二詞正確 |
| --- | ---: | ---: | ---: | ---: |
| 0..5，答案角色已有曝光 | 143/144 | **115/144** | 143/144 | 115/144 |
| 6..14，僅其他詞位置可能曝光 | 136/216 | **1/216** | 142/216 | 1/216 |
| 15..29，原訓練資料詞值未出現 | 224/360 | **0/360** | 244/360 | 0/360 |
| 15..29 且與 c、d 不相同 | 200/312 | **0/312** | 218/312 | 0/312 |

r2 各模型對 b6..14：seed101/fixed 0/54、101/varied 1/54、202/fixed 0/54、202/varied 0/54；b15..29 全部 0/90。四模型共用六個 anchors，這些分母是模型×題的評估次數，**不是相互獨立學生或 360 個全新訓練概念**。已曝光 b0..5 的 r2 分拆 train79/96、val20/24、test16/24，與先前 PR32 的範圍一致。b6..14 恰有一次正確：seed101 varied、a5,b6,c26,d17、r2，實際 `001010001100S` 等於標準答案；不應寫成 0。

raw 失敗例一：seed101 fixed，r2，a=0、b=6、c=18、d=26：

```text
Q:        010100100000000001100100100110100111100
expected: 000000001100S
actual:   000010000110S
```

連 r1（答案與 b 無關）也出現被干擾的錯誤：

```text
Q:        010100010000000001100100100110100111100
expected: 000000S
actual:   000010S
```

本輪讀回 Git 中 `raw_cases.jsonl`，另外用獨立算式重建 1,440 個合法 Q／答案，檢查唯一 1,440 model×Q、各 b 範圍、全對數與 STOP，全部 PASS。它是**第二次靜態驗收**，未重訓／未重跑整批 NN 前向，不能把它說成雙重神經獨立重現。

成本：原封存 gate 8,640 NN forward；新題 14,400 forward；合計 23,040。每次 dense 層 10,432 MAC；新題 **150,220,800** MAC，含 gate **240,353,280** MAC（不含 tanh/bias/記憶/I/O），optimizer 0。後續只有下載核對與統計，沒有新增種子、更新、擴容或隱性重訓。NVIDIA/OpenRouter：此環境未提供可授權的外部 worker 入口，呼叫 **0**；Codex 本機 **0**；Gemini **0**。

## 限制、反例與後續實驗

這是舊 checkpoint 的固定輸入介入，不是事前未被其他研究人員看過的盲測；使用原 test anchors 並觀察超出原 b 訓練取值的分布。這批網路沒有展現對新第二詞 ID 的可遷移複製能力，但**不能據此證明 SLE 不可學、所有模型都只能死記，或一定是因為詞的角色改變而失敗**。b6..14 在不同位置可能已出現，b15..29 甚至沒當過訓練資料詞，高位元分布改變是競爭解釋。停止位置 1440/1440 只代表這一固定長度、參數任務的停止能力，不是內容複製能力。

**[更新]** PR29 確實已有 train/val/test 的 (a,b) 組合保留，缺口是「第二答案詞 ID 超出 0..5」的詞域遷移，而不只是有沒有保留 (a,b) 配對。**[取代]** 把「開始建立未見前兩詞組合」直接視為當下唯一未測事項。**[原因]** 查核 PR29 真實 split，並完成 b=0..29 真神經推論。**[狀態]** 本四網路的固定範圍失敗，信心高；機制與一般化到別的教材／架構，信心低。

下一棒（NN/Pro/Codex 協調）：先審核本次全部失敗和來源 hash。若要真正識別「角色曝光」和「詞值分布」，可在**另一個新實驗**凍結 b6..14 位置覆蓋平衡的訓練課程／等更新控制；不能在這批 checkpoint 看分數後補訓冒稱原盲測。不要碰正在進行的 Codex F2、Pro UR1 或現行 main。
